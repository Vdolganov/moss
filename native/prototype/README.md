# MOSS 0.9.0 — руководство

**Русский** · [English](README.en.md)

MOSS 0.9.0 — единое стабильное приложение для оригинальной RG35XX и Windows. GRANULAR включён; отдельного приложения MOSS-GRANULAR больше нет. Четыре дорожки, 32 секвенции, 32 SONG по 64 слота, аудио 32 kHz / 1024 стереофрейма. Подготовленная библиотека — 32 × 1 MiB.

MONO: пять страниц, двадцать параметров. GRANULAR: PLAY / SCAN / TEXTURE / ENVELOPE / CLOUD, восемь зёрен на дорожку. Пять эффектов, до двух одновременно на дорожке и мастере. Подробности: [MONO](../../docs/MONO-v09.md), [GRANULAR](../../docs/GRANULAR-INSTRUMENT.md), [REEL](../../docs/REEL-v1.md), [POND](../../docs/AMBIENT-RESEARCH-v08.md), [DRIVE/ORBIT](../../docs/FX-CHARACTER-v1.md), [LOCK ONLY/REPEAT](../../docs/TRIGLESS-LOCKS-PLAN.md), [SWING/SHIFT](../../docs/SWING-v1.md).

Сохранения — MS15, чтение MOS5…MS14; SONG остаётся SON1. Сохраняйте оригиналы: старые бинарники не читают MS15, новые MONO/POND меняют звук патчей. [Релиз и аппаратные проверки](../../releases/0.9.0/RELEASE.md). Браузерный прототип и аппаратный LAB — отдельные инструменты.

## Запуск и обновление

Открой Consoles → APPS → MOSS. При первой инициализации пустой библиотеки проектов создаётся SLOW SIGNAL с ORGANISM / MONO / FM; выбери его, нажми A, затем START. Пункта создания DEMO в меню нет.

Своя секвенция: ATLAS / SEQUENCES → **+ NEW SEQUENCE** → EMPTY либо существующая секвенция для независимой копии → введи имя → START. Затем GRID → **+ ADD TRACK** → выбери инструмент → A. EMPTY создаёт пустую секвенцию с темпом 120 BPM; копия сохраняет настройки источника. Строка добавления остаётся видимой и при четырёх дорожках, но сообщает о достигнутом пределе.

Новые сохранения — MS15. MOS5…MS14 читаются без перезаписи до сохранения. Старые MOS5 сокращаются до первых четырёх дорожек, четырёх слотов сэмплера и двух активных эффектов в цепочке. MOS3/MOS4 не поддерживаются. При переходе с MOSS-GRANULAR переносите комплект проектов и библиотеки целиком по [инструкции установки](../../README.md).

Перед обновлением сохрани копию оригинальных проектов и пользовательских файлов. Обновляй приложение, сохраняя `projects/`, `samples/`, имена образцов, `imports/` и `captures/`; тестовые WAV из чистого пакета не должны заменять собственный банк. Удаление проекта не удаляет связанные WAV.

Launcher включает performance с верхним пределом штатных **1.008 GHz**, без разгона. При выходе он возвращает прежний governor и пределы частоты.

## Кнопки и навигация

**Параметры слева направо: Y / B / A / X.** На Windows этим позициям соответствуют **Z / X / C / V**. Удерживай кнопку поля: ←/→ меняют значение на единицу, ↑/↓ — крупным шагом. Для процентов, уровней и velocity это 10; Hz и миллисекунд — 100; высоты — октава; LENGTH и CYCLE — 16 клеток. Списки вариантов перелистываются по одному. Долгое удержание ускоряет повтор. После такого жеста отпускание кнопки не выполняет её короткое действие.

| RG35XX | Windows | Действие |
|---|---|---|
| D-pad | Стрелки | Выбор шага, объекта или пункта |
| Y / B / A / X + стрелки | Z / X / C / V + стрелки | Первое / второе / третье / четвёртое поле |
| A коротко | C | Открыть, подтвердить, включить триггер, прослушать VOICE |
| B коротко | X | Назад или отмена |
| X коротко | V | Прослушать TAPE/WAV; включить или обойти FX |
| Y коротко | Z | Не меняет страницу |
| L1 / R1 | Q / E | Предыдущий/следующий банк; в ATLAS — SEQUENCES/SONGS, в GRID — дорожка |
| L2 / R2 | [ / ] | GRID / MIX / TAPE либо PATTERN / VOICE / SPACE |
| L1 + стрелки | Q + стрелки | Вложенный слот, банк CORE/CHARACTER локов или FX |
| R1 + ←/→ | E + ←/→ | Страница GRID или списка |
| L1 + R1 | Q + E | Контекстные опции, если они доступны |
| START | Space | Старт/стоп транспорта; в имени — сохранить |
| SELECT + стрелки | Tab + стрелки | Темп 30–240 BPM без сброса музыкальных часов |
| SELECT коротко | Tab | ATLAS; в диалогах — закрыть/отменить |
| MENU, удержать 2 секунды | Esc, удержать 2 секунды | Сохранить и выйти, если запись описана в отчёте |

L1/R1 переключает STEP / VOICE LOCKS / FX LOCKS / CYCLE в PATTERN, CORE / CHARACTER в синтезаторном VOICE, LEVELS / MASTER FX в MIX и SOURCE / EDIT / LIBRARY в TAPE. В VOICE сэмплера эти кнопки выбирают слот, в SPACE — эффект. Вложенный жест L1+стрелки не перелистывает банк при отпускании. Короткое SELECT после изменения темпа также не срабатывает. R1+←/→ перелистывает сетку по 16 клеток, сохраняя позицию внутри страницы; на последней неполной странице — до ближайшей доступной клетки. В MIX вкладки LEVELS / MASTER FX видны также внутри эффекта.

Вкладки и банки подписаны на экране. Цвет привязан к физической кнопке: Y — тёплый, B — голубой, A — шалфейный, X — сиреневый. Выбранный объект обозначен нейтральной рамкой. При удержании параметра сохраняется его единица измерения; диагностических таймеров удержания нет.

## Ввод имени

Все имена — новый проект, переименование проекта/дорожки/образца, сохранение слайса или набора слайсов — вводятся одной экранной клавиатурой. Доступны **A–Z, 0–9, пробел и дефис**, отдельные DEL и SAVE. Предел — **24 символа**, счётчик виден над полем.

- Стрелки выбирают клавишу; A вводит символ или нажимает DEL/SAVE.
- X удаляет символ перед кареткой; START сохраняет.
- L1/R1 перемещает каретку; B или SELECT отменяет ввод.
- Исходное имя выделено целиком. Первый символ заменяет его, X очищает. L1/R1 снимает выделение и ставит каретку в начало/конец.
- Пустое имя не сохраняется. Ошибка записи сохраняет введённый текст для повторной попытки; при нарезке сохраняется и диапазон.

## PATTERN и независимые циклы

Открой дорожку из GRID кнопкой A. Стрелки выбирают шаг в сетке 8×2, переход за край страницы открывает следующую. Короткое A включает/выключает триггер. Светлая клетка — включённый шаг, рамка — выбор, верхняя черта — playhead, нижняя линия — конечная длительность выбранного события, маленький маркер — локи. PLAY относится к циклу текущей дорожки.

L1/R1 выбирает банк. Четыре поля всегда идут в порядке **Y / B / A / X**:

| Банк | Y | B | A | X |
|---|---|---|---|---|
| SAMPLER STEP | VELOCITY 0–127 | FADE IN 0–5000 ms | LENGTH: FULL или конечная длина | PROB 0–100% |
| Синтезатор STEP | NOTE C1–C7 | VELOCITY 0–127 | LENGTH в шагах | PROB 0–100% |
| SAMPLER VOICE LOCKS | PITCH ±24 полутона | START % | END % | LEVEL % |
| TIMING 1/2 | CYCLE: число клеток | STEP: 1/8, 1/16, 1/32, 1/64 | REPEAT | TYPE |

У каждого SAMPLER **четыре независимых рисунка ударов**. Именованные слоты 1–4 (C3–D#3) постоянно видны над сеткой. **L1+стрелки** выбирает слот; сетка показывает его удары. Пустой слот можно выбрать, но перед включением удара ему нужно назначить звук в VOICE. Несколько слотов могут срабатывать одновременно; повтор одного слота плавно сменяет его голос, остальные продолжают звучать.

**LENGTH = FULL** хранится как 0 и играет выбранный диапазон один раз до конца. Конечное значение ограничивает именно этот удар, с коротким отпусканием против щелчков. Короткий исходник всегда заканчивается естественно; увеличение LENGTH не зацикливает и не растягивает его. FADE IN относится к удару; старые fade-out сохраняются в данных, а фейды TAPE записываются в сам WAV.

CYCLE меняет музыкальную длину, сохраняя скрытые события за новым концом. STEP меняет только разрешение: 15 клеток при 1/8 становятся 30 при 1/16, 60 при 1/32 и 120 при 1/64. Время событий, конечные длительности и BPM остаются прежними. Предел — **512 тиков 1/64**, то есть 64 восьмых. События между линиями грубой сетки продолжают звучать и отмечаются в клетке; для редактирования верни мелкую сетку. Частичный конец обозначен LAST CELL.

VOICE LOCKS повторяет страницы инструмента: пять у MONO/GRANULAR, две у ORGANISM/FM; L1+стрелки выбирает вложенный банк. FX LOCKS поддерживает все страницы выбранного эффекта. `--` наследует, RESET возвращает базу. LOCK ONLY меняет звучащий голос без перезапуска ноты. TIMING содержит TYPE, REPEAT и CYCLE/STEP, на второй странице — SWING/SHIFT; подробности в руководствах выше.

FX-локи относятся к **общей шине дорожки**, через которую проходят все её слоты, и привязаны к имени эффекта при перестановке. Эффект должен быть включён. OPTIONS показывает LENGTH TO CYCLE END на STEP и CLEAR CURRENT LOCK BANK только там, где есть локи текущего банка.

## VOICE: сэмплер и импорт

В VOICE стрелки или L1/R1 выбирают любой из четырёх слотов. A прослушивает назначенный звук, на пустом слоте открывает библиотеку. Для замены используй OPTIONS → ASSIGN / REPLACE SAMPLE, для освобождения — REMOVE ASSIGNMENT. Один WAV можно назначить разным слотам с собственными PITCH / START / END / LEVEL. Встроенной автоматической нарезки нет.

Прямой импорт в слот:

1. В выборе образца открой **+ IMPORT FROM DEVICE**.
2. Выбери WAV: X слушает полный файл, A открывает EDIT.
3. Поля Y / B / A / X задают START / END / FADE IN / FADE OUT. Короткое X слушает выбранный диапазон.
4. Короткое A открывает имя; введи его и нажми START или экранную SAVE.
5. Новый WAV сохраняется в библиотеке, назначается исходному слоту, экран возвращается в VOICE.

B/SELECT в имени возвращает к тому же EDIT. B из списка файлов закрывает список; B из импорта возвращает в VOICE без замены назначения. Ошибка, неподдерживаемый файл или заполненная библиотека сохраняют старое назначение.

## VOICE: синтезаторы

OPTIONS → CHOOSE INSTRUMENT выбирает SAMPLER / MONO / ORGANISM / FM / GRANULAR. Смена инструмента сохраняет его отдельные настройки, рисунки и локи; предыдущий голос гасится. Синтезатор имеет один музыкальный голос на дорожку. Четыре осциллятора/оператора внутри движка не означают аккордовую полифонию.

У MONO страницы CORE / COLOR / OSC / ENV / MOTION — все двадцать параметров описаны в [руководстве MONO](../../docs/MONO-v09.md). ORGANISM и FM сохраняют CORE / CHARACTER, по восемь параметров. L1/R1 меняет страницу, Y/B/A/X — четыре поля. Режим и пресеты находятся в L1+R1 OPTIONS. Пресет заменяет все базовые параметры инструмента, сохраняя режим и локи. MONO показывает реальный сигнал до эффектов и огибающие; диаграммы ORGANISM/FM остаются схематическими. A прослушивает; стрелки без модификатора выбирают ноту прослушивания.

## SPACE и MIX

Цепочка содержит ORBIT / POND / DRIVE / CRUSH / REEL, каждый тип один раз. **До двух эффектов включены одновременно на каждой дорожке и до двух на мастере** — максимум десять при четырёх дорожках. Для включения третьего сначала переведи один из двух в BYPASS.

Стрелки выбирают строку, A открывает параметры, X включает/BYPASS, **Y+↑/↓** перемещает эффект по цепочке. Обработка идёт сверху вниз. В настройках L1+стрелки выбирает эффект, B возвращает к цепочке. Порядок, настройки и локи сохраняются независимо от BYPASS.

ORBIT и DRIVE имеют CORE/CHARACTER, POND — TAIL/SPACE, REEL — COLOR/MOTION/LIFE/OUTPUT, CRUSH — одну страницу. L1/R1 меняет страницу. Все параметры доступны в локах дорожки. REEL разделяет насыщение, окраску/низы, глубину и частоту wow/flutter, дрейф, износ, провалы и шум. Хвосты delay/reverb продолжаются на пустых шагах.

В MIX / LEVELS выбери дорожку стрелками: поля LEVEL / PAN / MASTER / MUTE; короткое A меняет mute. L1/R1 открывает MASTER FX. Mute плавно закрывает дорожку вместе с SPACE. Мониторное усиление **180%** с ограничением пиков действует и на прослушивание, но внутренний захват берётся до него, поэтому повторный ресэмплинг не накапливает усиление.

## TAPE: файлы, диапазоны и библиотека

L1/R1 выбирает SOURCE / EDIT / LIBRARY; стрелки в EDIT выбирают диапазон, в LIBRARY — образец.

- **SOURCE → X:** список WAV; X слушает полный файл, A открывает EDIT.
- **EDIT:** Y / B / A / X + стрелки меняет START / END / FADE IN / FADE OUT. Для границ ←/→ — 1 ms, ↑/↓ — 100 ms; удержание ускоряет. При расширении за лимит противоположная граница сдвигается. Короткое X запускает/останавливает диапазон, OPTIONS → AUDITION FULL SOURCE — весь исходник.
- **Короткое A в EDIT:** имя → START/SAVE. Сохраняется самостоятельный PCM16 WAV; исходник остаётся целым.
- **Несколько диапазонов:** OPTIONS → ADD NEXT RANGE; до 16. При нескольких диапазонах доступны SAVE ALL SLICES и REMOVE SELECTED SLICE. SAVE ALL запрашивает общее имя и добавляет номера. Автоматической нарезки при импорте нет.
- **LIBRARY:** A редактирует копию, X слушает. OPTIONS переименовывает или удаляет неиспользуемый образец. Для назначения открой слот VOICE.

Один подготовленный образец/диапазон — до **1 MiB PCM16**, общая библиотека — **32 образца / 32 MiB PCM**. Размер виден в EDIT. Длительность зависит от частоты и каналов: примерно 5.94 s stereo 44.1 kHz либо 23.78 s mono 22.05 kHz. SAVE ALL проверяет размеры и свободные места; ошибка сообщает число уже записанных файлов.

Длинный исходник прослушивается потоком через буфер 65 536 стереофреймов PCM16 / 256 KiB. Поддерживается RIFF WAV: PCM16/24/32 либо float32, mono/stereo, 8–96 kHz. WAV Extensible, RF64 и сжатые форматы не поддерживаются. При сохранении частота и каналы исходника сохраняются, автоматического downsampling нет. Поиск: `imports/`, `captures/`, `../../../MOSS-SampleLibrary/`, до 2048 файлов и пяти уровней папок.

Удаление требует подтверждения и недоступно, если образец нужен открытому/сохранённому проекту, Undo или восстановимой копии удалённого проекта. Оно не удаляет исходный полный WAV. Разметка диапазонов живёт только в сеансе; сохраняй нужные диапазоны перед выходом. Файловые операции TAPE не входят в Undo.

## Внутренний ресэмплинг

В SOURCE **Y+стрелки** выбирает MASTER или одну из существующих TR 01–TR 04, **B+стрелки** — 1–8 тактов. A начинает запись, повторное A заканчивает раньше. Остановленный транспорт запускается с начала; при воспроизведении захват начинается сразу. Длительность считается по BPM на старте, доступный предел виден на экране.

MASTER записывает сумму с мастер-эффектами, TR — дорожку с её SPACE, уровнем и панорамой до мастера. Внешнего входа/микрофонной записи нет. Готовый WAV сохраняется в `captures/take-NNNN.wav` и открывается в EDIT.

Во время **SAVING CAPTURE / PLAYBACK CONTINUES** WAV и его обзор готовятся в фоне; музыка и интерфейс продолжают работать. Завершённый PCM-буфер остаётся неизменяемым до успеха. При ошибке запись остаётся в RAM: A в SOURCE повторяет сохранение, OPTIONS → DISCARD CAPTURE отменяет её. До сохранения/отмены заблокированы выход, смена проекта и структурные операции.

Открытие исходника, запуск прослушивания, сохранение слайса и удаление образца останавливают транспорт; прослушивание не запускает его обратно. Сохранение проекта и завершённого захвата не требует остановки.

## Секвенции, SONG, Undo и выход

ATLAS содержит вкладки SEQUENCES / SONGS. SEQUENCES хранит до 32 секвенций и строку + NEW SEQUENCE; SONGS — до 32 аранжировок и + NEW SONG. GRID — до четырёх дорожек и + ADD TRACK. OPTIONS отфильтрованы по экрану и состоянию: управление проектом/дорожкой находится в соответствующих списках, выбор инструмента/пресета — в VOICE, файловые операции — в TAPE. Пустое меню не открывается.

TRACK OPTIONS и SEQUENCE OPTIONS содержат RENAME / DUPLICATE / DELETE. Копия получает COPY; копия дорожки сохраняет рисунки, локи, назначения, оба банка и FX. Удаление требует подтверждения A. SAVE SEQUENCE сохраняет без выхода; знак + у имени показывает несохранённые правки.

UNDO LAST EDIT отменяет один последний жест проекта, включая изменение структуры дорожек; повторное Undo меняет два состояния местами. Структурные операции и Undo останавливают транспорт. Проектные операции не входят в Undo: RESTORE DELETED SEQUENCE в ATLAS возвращает один последний удалённый проект при наличии места, следующее удаление заменяет эту копию.

**SONG:** выбери SONGS → + NEW SONG → имя. В пустом списке A на + ADD SEQUENCE добавляет существующую секвенцию либо открывает создание новой. У каждой строки — повторы и длина одного повтора в тактах 4/4. По умолчанию длина округляется вверх по самой длинной дорожке: 15/16 шагов при 1/16 дают один такт, а не ожидание совпадения циклов.

Поля SONG слева направо: **Y POSITION / B REPEATS / A BARS / X LOOP**. Y+↑/↓ двигает строку, B+←/→ меняет повторы по одному (↑/↓ по десять), A+←/→ такты по одному (↑/↓ по четыре). X+стрелка включает/выключает повтор всего SONG. R1+←/→ листает список по четыре строки. START играет с выделенной строки, повторный START останавливает; если выбран + ADD, воспроизведение начинается с последнего существующего слота.

У SONG **один общий BPM**, SELECT+←/→ по одному, SELECT+↑/↓ по десять. Внутри слота полиритмы продолжаются через повторения без сброса; при переходе к следующему слоту локальная позиция секвенции начинается с нуля. LOOP OFF завершает SONG с затуханием эффектов. BPM отдельных файлов используется при самостоятельном воспроизведении секвенций.

A на строке открывает секвенцию, B из её GRID или короткий SELECT сохраняет и возвращает в SONG к той же строке. X заменяет секвенцию в слоте и заново назначает один повтор и длину по длиннейшей дорожке. OPTIONS позволяет сохранить/переименовать SONG, отменить правку, дублировать/убрать слот или **COPY SEQUENCE AS NEW**: назвать независимую вариацию, заменить ей текущий слот и открыть редактор. Обычный DUPLICATE SLOT ссылается на тот же файл секвенции; её правки будут слышны во всех таких слотах.

Во время SONG можно смотреть список и менять общий BPM; для правок структуры сначала START STOP. Перед запуском все нужные секвенции заранее загружаются в память, отсутствующие файлы/сэмплы проверяются. Чтения с карты в момент перехода нет. Эффекты соответствующих дорожек сохраняют хвосты, прежние ноты завершаются; краткий переход ограничивает щелчок при смене маршрута. Это один движок, без одновременного проигрывания двух полных секвенций.

SONG хранится отдельно в `projects/song-N.moss` (SON1); ссылки на существующие секвенции сохраняются. Удаление слота/SONG не удаляет секвенции и WAV. Секвенцию, используемую SONG или его Undo, удалить нельзя. Ошибка сохранения оставляет правки для повторной попытки. Длительность уже созданного слота не меняется автоматически при последующем изменении цикла секвенции.

Для выхода удерживай MENU две секунды либо открой **ATLAS → OPTIONS → EXIT MOSS**. Ошибка сохранения оставляет приложение открытым. Проекты и WAV записываются через временный файл и замену; отключение питания во время записи всё равно может повредить файловую систему.

В нативной версии пока нет сцен, банков паттернов A–D, метаданных тональности/лада и JSON-переноса из браузерного прототипа.

## Сборка и проверка

`node scripts/build.cjs` собирает ARM/Windows и выполняет полный набор нативных проверок. `scripts/package.py` проверяет бинарники, ABI и аппаратные результаты для точного хеша. Garlic использует SDL 1.2/evdev, Windows — GDI/waveOut. В аудиорендере нет файловых операций и выделения памяти; отчёты записываются асинхронно. `late_intervals` — диагностический интервал, а не точный счётчик слышимых обрывов.

Актуальные результаты — в [релизе 0.9.0](../../releases/0.9.0/RELEASE.md). Датированные отчёты 0.5.x–0.9.0-dev сохранены как история с исходными хешами.
