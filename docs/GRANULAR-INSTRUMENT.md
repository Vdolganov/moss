# GRANULAR / LENS · экспериментальная 0.6.0-dev

**Русский** · [English](GRANULAR-INSTRUMENT.en.md)

GRANULAR — пятый нативный инструмент MOSS, выбранный после браузерного сравнения «Срез / Поле / Линза». 13 ноября 2026 пользователь выбрал **Линзу / LENS**. Один подготовленный сэмпл превращается в облако максимум из **восьми одновременно звучащих зёрен на дорожку**. Сохраняются четыре дорожки, до двух эффектов на каждой и до двух на мастере.

Это экспериментальное расширение. Основное [руководство 0.5.2](../native/prototype/README.md) описывает стабильную версию; изменения GRANULAR перечислены здесь. Отдельная установка на RG35XX с GarlicOS 1.4.9 и аппаратные проверки завершены; условия и результаты — в [отчёте](GRANULAR-NATIVE-v1.md).

## Первый звук

На подготовленной консоли открой **APPS → MOSS-GRANULAR → LENS STUDY**, затем дорожку LENS и вкладку VOICE. **START** запускает секвенцию. Демо использует скопированный образец AIR; остальные секвенции и библиотека также доступны в отдельной копии.

1. Создай дорожку с **GRANULAR** либо открой VOICE → L1+R1 → CHOOSE INSTRUMENT → GRANULAR.
2. На пустом VOICE нажми **A**, чтобы назначить образец. OPTIONS → ASSIGN / REPLACE SAMPLE заменяет его; REMOVE ASSIGNMENT снимает назначение.
3. Для своего WAV выбери **+ IMPORT FROM DEVICE**, файл и ручной диапазон в EDIT. Задай имя и сохрани: подготовленный WAV попадёт в библиотеку, назначится облаку, и откроется VOICE. Это тот же путь подготовки, что у TAPE; отмена или ошибка сохраняет прежнее назначение.
4. Нажми **A** для прослушивания: gate открыт две секунды, затем звучит отпускание FADE. Для секвенции включи триггер в PATTERN и нажми START.

У GRANULAR **одно назначение на дорожку**, не четыре слота SAMPLER. Подготовленный PCM16-образец ограничен **1 MiB**. START/END внутри инструмента не уменьшают объём в памяти; для короткого файла сохрани отдельный диапазон через TAPE/импорт.

## Управление

Короткие **L1/R1** выбирают PLAY / SCAN / TEXTURE. Четыре поля слева направо — **Y / B / A / X**; на Windows — **Z / X / C / V**. Удерживай кнопку и меняй значение стрелками: ←/→ точно, ↑/↓ крупно. Отпускание после изменения не запускает короткое действие.

| Банк | Y | B | A | X |
|---|---|---|---|---|
| PLAY | SPEED −3.00…3.00× | PITCH −24…+24 полутона | SIZE 1–500 ms | DENSITY 0–128 зёрен/с |
| SCAN | POSITION 0–100% | START 0–99.9% | END 0.1–100% | JITTER 0–500 ms |
| TEXTURE | SPREAD 0–100% | IRREGULAR 0–100% | CUTOFF 20–14000 Hz | FADE 0–9000 ms |

SPEED двигает точку рождения зёрен по источнику; отрицательное значение разворачивает сканирование. PITCH меняет скорость чтения самих зёрен независимо от сканирования. SIZE задаёт их длительность, DENSITY — частоту попыток рождения. При заполнении восьми голосов новые попытки пропускаются: высокая плотность не расширяет лимит.

POSITION перемещает головку внутри START–END. Во время звучания поле показывает текущую позицию; удержание Y позволяет редактировать её. START/END ограничивают **сканирование точек рождения**, а не чтение каждого зерна или исходный WAV. JITTER смещает точку рождения; зерно может читать за пределами диапазона и оборачивается по полному источнику. SPREAD задаёт стереоразброс, IRREGULAR — нерегулярность рождений, CUTOFF — фильтр, FADE — общую атаку и отпускание ASR.

Короткое **X** замораживает головку (**FREEZE**); рождение и чтение зёрен продолжаются, пока открыт gate. На Windows это **V**. Короткое A остаётся прослушиванием или назначением пустого источника.

## PATTERN и Линза

NOTE транспонирует облако относительно **C3**: при C3 и PITCH 0 чтение идёт на исходной высоте. LENGTH удерживает gate; по его окончании действует отпускание FADE. В VOICE LOCKS доступны те же 12 параметров. **L1+стрелки** выбирают вложенный PLAY / SCAN / TEXTURE; обычные L1/R1 продолжают выбирать STEP / VOICE LOCKS / FX LOCKS / CYCLE. `--` наследует базовое значение. Лок POSITION явно перемещает головку при триггере.

Внешний контур Линзы — заранее подготовленный обзор реального источника. Маркер показывает головку; расширяющиеся кольца — возраст зёрен, короткие дуги — их чтение. UI получает атомарные снимки аудиодвижка и не придумывает движение отдельными часами. Пустой источник показывает NO SAMPLE и A ASSIGN SAMPLE.

## Файлы, проверка и ограничения

Экспериментальная версия читает **MOS5/MOS6** и сохраняет **MOS7**: назначение, FREEZE, 12 параметров и локи. Стабильная **0.5.2 не читает MOS7**. Загрузка сама по себе не меняет оригинал; последующее сохранение использует новый формат. Работай с копиями секвенций и сохраняй исходные MOS5/MOS6 отдельно.

Установлен отдельный **MOSS GRANULAR** рядом со стабильным **MOSS 0.5.2**, с отдельными рабочими данными. Оригиналы проектов, SONG, WAV, имён и captures сохранены на компьютере; библиотека скопирована, демо добавлено новым файлом. Контрольные суммы исходных секвенций и стабильного бинарника после установки совпадают. Данные этих двух приложений автоматически не синхронизируются.

Windows-проверки существующих сценариев и гранулярной интеграции, UBSan и функциональные проверки на ARM прошли. В 23 минутах аппаратных нагрузочных прогонов не зарегистрировано превышений аудиобюджета, опозданий или медленных UI-кадров; длительности, два хеша сборок и ограничения проверки перечислены в отчёте. DSP — собственная реализация обычного гранулярного синтеза, не перенос кода Mangl. Линейная интерполяция не гарантирует подавления алиасинга при большой транспозиции вверх.

[Браузерный этюд](../visual%20prototype/granular.html) остаётся без звука, с синтетическим источником и собственным хранилищем. В нём короткое **C / A** включает FREEZE; это отдельное управление этюда. Нативный FREEZE — **X / V**. Все три вида доступны для сравнения, выбранный нативный вид — LENS.
