# MOSS native 0.4.0 · проекты, дорожки и прослушивание TAPE

## Overview

Уточнение реализованных сценариев нативного прототипа, 11 ноября 2026. Режим Operate, существующая графитовая система и четыре позиционных цвета из [DESIGN.md](../../DESIGN.md) сохранены. Дополнение описывает управление содержимым и обратную связь TAPE; не утверждает готовность всей версии или успешное испытание RG35XX. Синтезаторные экраны описаны отдельно в [native-synths-0.4.md](native-synths-0.4.md).

Нативный проект теперь имеет имя и 0–8 именованных дорожек; ATLAS хранит до 32 проектов. Новый проект начинается пустым при 120 BPM. Демо SLOW SIGNAL создаётся отдельной командой. Формат хранения MOS4 сохраняет имена и число дорожек; MOS3 не конвертируется. При согласованном обновлении старые проекты сбрасываются после резервного копирования, сэмплы и исходные WAV сохраняются.

## Layout

ATLAS показывает именованные проекты с числом дорожек и BPM, по пять строк на странице; последняя строка — + NEW PROJECT. GRID сохраняет колонки TRACK / VOICE / SPACE, показывает по пять строк и + ADD TRACK до лимита восьми. MIX показывает текущую группу до трёх дорожек. Фокус — существующая нейтральная рамка; дополнительных цветов инструментов или действий нет.

## Components

### Проекты и дорожки

| Место | Действие | Результат и восстановление |
|---|---|---|
| ATLAS: + NEW PROJECT или OPTIONS → NEW PROJECT | Ввести имя, A | Пустой проект открывается в GRID; не заполняется демо-дорожками |
| ATLAS OPTIONS | RENAME / DUPLICATE / DELETE PROJECT | Имя сохраняется; копия с суффиксом COPY открывается в GRID; удаление требует подтверждения |
| ATLAS OPTIONS → RESTORE DELETED PROJECT | Восстановить | Последний удалённый проект возвращается в свободный слот; следующая операция удаления заменяет восстановимую копию |
| GRID: + ADD TRACK или OPTIONS → ADD TRACK | Выбрать SAMPLER / MONO / ORGANISM / FM, A | Новая дорожка открывается в PATTERN с выключенными шагами; B/SELECT отменяет добавление |
| GRID OPTIONS → TRACK OPTIONS | RENAME / DUPLICATE / DELETE | Копия вставляется рядом и сохраняет данные дорожки; удаление требует подтверждения; доступен UNDO LAST EDIT |
| GRID OPTIONS → PROJECT OPTIONS | RENAME / DUPLICATE / DELETE | Те же операции с открытым проектом, что в ATLAS |

Имена содержат до 24 символов. ←/→ выбирает позицию, ↑/↓ символ, A сохраняет, B/SELECT отменяет. Пустое имя оставляет редактор открытым с сообщением. Подтверждение удаления принимает A и отменяется B/SELECT.

UNDO LAST EDIT хранит одно предыдущее состояние проекта и включает создание, переименование, копирование и удаление дорожки. Повторное Undo меняет состояния местами. Операции над файлами проектов не входят в Undo; для удаления есть отдельная восстановимая копия. Структурные изменения и Undo останавливают транспорт; незавершённый захват блокирует изменение структуры. Удаление проекта не удаляет его WAV, а ссылки восстановимой копии защищают соответствующие assets от удаления.

### TAPE: размер выделения

Выделение ограничено 1 MiB декодированного PCM16: максимум фреймов равен `1048576 / (число каналов × 2)`. Поэтому допустимая длительность зависит от частоты и каналов, а не от битности исходного файла. Например, stereo 44.1 kHz даёт около 5.94 s, mono 22.05 kHz — 23.78 s. Импорт длинного WAV выбирает допустимый начальный диапазон.

Когда END расширяется сверх лимита, START сдвигается следом. Когда START расширяется назад сверх лимита, END сдвигается назад. Выделение остаётся непустым; фейды ограничиваются его длиной. Размер и границы остаются видимыми, исходник не меняется. Сохранение создаёт отдельный PCM16 WAV. END на конце источника включает последний фрейм, несмотря на округление отображаемых ms.

### TAPE: полное и фрагментное прослушивание

- В списке IMPORT WAV короткое X / C запускает или останавливает полный выделенный файл; A открывает его в EDIT.
- В EDIT короткое X / C запускает или останавливает выбранный диапазон с его фейдами. OPTIONS → AUDITION FULL SOURCE запускает весь исходник.
- Маркер связан с фактическим потреблением фреймов аудиодвижком. Это позиция прослушивания, в отличие от статических синтезаторных MODEL.
- Правка границ или фейдов, смена материала и уход с экрана останавливают прослушивание. Его запуск останавливает транспорт; автоматического возобновления нет. Во время незавершённого захвата прослушивание недоступно.

Прослушивание не ограничено лимитом сэмпла 1 MiB. Полный WAV читается порциями через фиксированный буфер 65 536 стереофреймов PCM16 (256 KiB); файловые операции и декодирование выполняются вне аудиопотока. Существующие ограничения RIFF WAV и файлового позиционирования `long` сохраняются. Буфер не гарантирует бесперебойную работу любой SD: отчёт содержит `stream_underruns`, а проверка устройства ещё предстоит.

## Do's and Don'ts

- Сохранять имена как данные пользователя, отдельную строку создания, подтверждение удаления и явный путь восстановления.
- Сохранять единый принцип управления: A применяет, B/SELECT отменяет, L1+R1 открывает OPTIONS, числовые значения меняются удержанием слота со стрелками.
- Не трактовать предел сохраняемого сэмпла как запрет прослушивания полного исходника и не загружать полный длинный WAV в RAM.
- Не считать локальные тесты доказательством скорости SD или аудиопроизводительности RG35XX.

Из браузерных сценариев пока отсутствуют метаданные тональности/лада, JSON-перенос, сцены и паттерны A–D. Браузерные файлы и токены не изменены.
