Отмена жеста / проекты

Удерживайте цветную кнопку и нажимайте стрелки. ←/→ — точно, ↑/↓ — крупно. Отпускание сохраняет, Tab отменяет весь жест. В STEP: C + стрелки меняет длину ноты в шагах. В CYCLE: Z + стрелки задаёт 1–64 шага этой дорожке. Q/E выбирают видимый объект, Q+E открывает опции. V коротко переключает STEP / VOICE LOCKS / FX LOCKS / CYCLE и разделы MIX/TAPE.

Попробовать

ATLAS → проект → GRID / MIX / TAPE. Tab возвращает к проектам. В GRID выберите дорожку, чтобы открыть PATTERN / VOICE / SPACE.
