Сценарии интерфейса · без звука

Кликни по экрану, чтобы управлять клавиатурой. Масштаб 1× сохраняет читаемый размер; на узком окне экран прокручивается. Кнопка масштаба переключает 1×, 1.5× и обзор «по ширине». Мышь тоже работает: выбирай строки, вкладки и параметры. Shift + Tab возвращает фокус за пределы экрана.

Зажми Z, X, C или V и нажимай стрелки: ← / → меняют соответствующий параметр на единицу, ↓ / ↑ — крупнее. Удержание стрелки ускоряет изменение. 16 / 64 под гридом меняет число шагов на странице, сохраняя выбранный шаг. По умолчанию включено 64; с клавиатуры — Q + E → GRID VIEW → C. ↑ / ↓ переходят на соседнюю строку, E + ← / → — на страницу выбранного размера. В четырёхчастной нарезке короткое Y/B/A/X выбирает и запускает беззвучный предпросмотр участка; MENU (Escape) возвращает назад.

В PATTERN у каждого включённого эффекта своя вкладка: ORBIT LOCKS, REEL LOCKS и т. д. Порядок соответствует цепочке; выключение скрывает вкладку, сохраняя локи. Q / E переключают вкладки. Q + ← / → выбирает слот сэмплера или участок TAPE; Q + ↑ / ↓ — страницу параметров. Для вложенных страниц активный таб показывает счётчик и стрелки, слева от параметров — шкала. В TAPE участки имеют отдельный горизонтальный счётчик.

Зажми Q (L1), чтобы увидеть подсказку: ↑ — предыдущая страница, ↓ — следующая. Стрелки активной вкладки можно нажимать мышью. Долгое удержание Q для чтения подсказки не переключает вкладку при отпускании. Слоты сэмплера монохромные: светлый фон выделяет выбранный слот, отдельная инверсия ноты — воспроизведение.

В TAPE выбранный участок выделен яркой волной и границами START/END; метка кнопки остаётся читаемой над узкими участками. Линия с треугольником показывает предпросмотр. В FINE стрелки у краёв означают границы вне текущего окна.

Лок: удерживай соответствующую Z/X/C/V и нажми Escape, либо открой Q+E → PARAMETER. SET задаёт событие, CLEAR удаляет только этот лок, RESET TO BASE возвращает базовое значение на шаге. -- означает отсутствие события, ◆ — значение лока, ◇ и RST — возврат к базе. Единицы Hz/ms/% сохраняются.

В TAPE: SAVE KIT добавляет комплект в библиотеку; SAVE SELECTED + ASSIGN назначает только выбранный участок исходному слоту; SAVE KIT + ASSIGN FOUR заменяет четыре назначения после подтверждения. Черновик границ сохраняется отдельно от готовых сэмплов и восстанавливается при открытии источника. Одно редактирование отменяется через Q+E → UNDO LAST EDIT.

Для имени можно использовать панель символов или нажать TYPE ON KEYBOARD. В текстовом режиме Enter сохраняет, Escape возвращает панель. В списках Q/E не выбирают строки: используй стрелки. Недоступные пункты меню показывают причину.

Сценарии и файлы

Эти переходы открывают обычные экраны приложения. Данные хранятся только в этом браузере. Экспорт — отдельный формат дизайн-прототипа; он не заменяет проекты на Anbernic. Предпрослушивание, захват, индикаторы и портреты звука моделируются визуально. WAV читается только для формы волны.

WAV и папки можно добавить кнопками выше. Перетащи WAV на окно, чтобы открыть его для нарезки.
