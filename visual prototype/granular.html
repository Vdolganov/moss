Без звука. Волна и зёрна — модель для сравнения интерфейсов. Переключение варианта сохраняет все настройки.

Поле

Зёрна рождаются над сэмплом и растворяются по мере жизни. Наклон показывает высоту, разлёт — ширину облака.

Почувствовать разницу

SCATTER в банке SCAN: 100% — весь диапазон, 0% — точная позиция. START / END ограничивают материал. C удерживает якорь; при полном разбросе облако от него не зависит.
