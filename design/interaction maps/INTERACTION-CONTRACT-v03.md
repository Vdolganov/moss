# MOSS — предлагаемый контракт взаимодействия v0.3

Дата: 10 ноября 2026. Статус: проработка, не описание уже внедрённой версии. Прототип app.js/model.js не изменён. Карты находятся в `design/interaction maps/index.html`; пользовательские сценарии — в `UX-SCENARIOS-v03.md`.

## Смысл управления

Объект → основная вкладка → элемент → параметр.

- L1/R1: предыдущий/следующий видимый объект. ATLAS: проект; GRID/редактор/LEVELS: дорожка; SCENES: слот сцены; TAPE: сэмпл. В MASTER FX и пустом списке пара неактивна. Границы без зацикливания; удержание не получает иной скрытой функции.
- L2/R2: основные вкладки текущего уровня. Проект: GRID/MIX/TAPE. Дорожка: PATTERN/VOICE/SPACE. ATLAS: неактивны. Вложенные вкладки выбираются D-pad + A, независимо от текущего фокуса курки продолжают работать с основной строкой.
- D-pad: локальный фокус. Перемещение не выполняет разрушительных действий, не загружает проект, не применяет сцену и не назначает сэмпл.
- A/B/X/Y + D-pad: параметр 1/2/3/4 текущего банка. На PC это Z/X/C/V. Подписи слотов всегда видимы. ←/→ точно, ↑/↓ крупно, повтор ускоряет числа. Списки и булевы параметры не перескакивают через значения из-за числового ускорения.
- A коротко: активировать выбранную команду или триггер. B коротко: закрыть временное меню либо подняться на один уровень. X коротко в PATTERN: шаг/поля. Y коротко в PATTERN: STEP/LOCKS.
- START: транспорт. SELECT в обычном состоянии: ATLAS; в меню: отменить меню; во время жеста: отменить жест. При активном CAPTURE действует специальная политика выхода ниже.

## Контекст и приоритет

1. Ввод текста: буквенные клавиши принадлежат тексту, фоновые команды заблокированы. Экранная клавиатура доступна с D-pad + A.
2. Меню: D-pad/A/B работают внутри него; фокус возвращается к инициатору. Если инициатор удалён, выделяется ближайший оставшийся объект или команда создания.
3. Активный жест: объект, слот и фокус зафиксированы. Курки не меняют цель редактирования. SELECT отменяет snapshot целиком; отпускание modifier завершает один жест Undo.
4. CAPTURE: source/length недоступны. Запрос ухода из TAPE разрешается только после явного решения о текущем захвате.
5. Обычная навигация: роли пар работают по таблице выше. Любое изменение выделения видно на экране.

Потеря фокуса прекращает repeat и завершает редактирование на уже показанном значении, без отложенного короткого нажатия. После возврата требуется новое нажатие. Смена вкладок не меняет музыкальные данные. Undo отменяет музыкальные изменения, а не перемещения по интерфейсу.

## Память позиции

В пределах сессии сохранять выбранный объект, основную/вторичную вкладку, шаг, страницу и фокус по projectId/trackId. Смена дорожки внутри VOICE/SPACE сохраняет вкладку. Возврат из редактора выделяет соответствующую строку GRID. Возврат из проекта выделяет его в ATLAS. После удаления выбор перемещается к соседнему объекту. Навигационное состояние отделено от сцен и Undo.

## Состояния и восстановление

| Состояние | Ожидаемая обратная связь | Доступные действия и восстановление |
|---|---|---|
| Пустой проект | Пустой GRID и ADD TRACK | Создать дорожку; транспорт не запускается |
| Пустая память | Понятное пустое состояние TAPE | Настроить SOURCE/LENGTH и CAPTURE; ASSIGN недоступно |
| Не назначенный lock | «—», базовое значение инструмента не потеряно | Первая стрелка назначает lock; SELECT отменяет весь жест и trigger |
| Активный жест | Цвет слота, подсвеченное значение, SELECT: CANCEL | Отпустить — завершить; SELECT — вернуть исходное состояние |
| Граница значения | Видимое минимальное/максимальное значение | Повтор не меняет число и не вызывает short tap |
| Захват выполняется | Прогресс, источник, длительность | FINISH, CANCEL; запрос выхода вызывает выбор STAY / SAVE / DISCARD |
| Захват завершён | Новый сэмпл выделен в памяти | Назначить явно; источник не заменяется |
| NEXT LOOP | Различать выбранную, текущую и ожидающую сцены | A повторно снимает очередь; STOP предлагается снимать очередь без загрузки |
| Ошибка сохранения | «Не сохранено», доступный экспорт | Данные остаются в памяти; экспортировать копию без ложного статуса успеха |
| Неверный JSON | Объяснение отказа импорта | Открытый проект не изменяется |
| Прерванный ввод имени | Меню закрыто, фокус восстановлен | Новый объект не создаётся |
| Разрешения / сеть | Для локального прототипа не нужны | Отдельные состояния микрофона/облака пока не проектируем |

## TAPE: политика прерывания

Для первого варианта предлагается удерживать capture в пределах TAPE. При любом запросе уйти показывать три действия: «Остаться», «Закончить и сохранить», «Отменить захват и выйти». Сохранение создаёт сэмпл в проекте, указанном в capture.projectId, до продолжения перехода. Сам переход не должен создавать или удалять запись молча. Модель фоновой записи с общим индикатором может стать отдельным следующим решением.

## Сцены: нерешённая область данных

Сейчас scene snapshot включает все tracks целиком, pattern index, length, BPM и master FX. Поэтому возвращаются состав и имена дорожек, назначения сэмплов и все паттерны. project.samples и capture не откатываются. Это достоверное текущее поведение, но его продуктовый смысл ещё нужно закрепить: «полный снимок музыкальной структуры» или «вариация звучания». Карта 05 показывает именно существующий полный снимок. Не сужать состав сцены незаметно.

## Другие решения для следующей итерации

1. Enter: оставить отдельной desktop-командой Activate, убрать альтернативный способ редактирования сфокусированного поля. Аппаратные сценарии проверять без Enter.
2. Один lock: добавить явную команду снять lock выбранного слота, сохранив остальные. Точный жест пока не выбран; CLEAR сейчас очищает весь шаг.
3. Undo: предусмотреть видимую команду внутри 640×480, доступную с аппаратных кнопок. Не считать Ctrl+Z аппаратным решением.
4. Смена инструмента: явно решить судьбу старых несовместимых locks; сейчас они сохраняются и могут стать невидимыми.
5. A–D и длина: сейчас общие для проекта, хотя находятся внутри дорожки. Явно показать область либо пересмотреть модель.
6. Порог короткого нажатия 300 мс проверить с человеком: пока удобство этой задержки не подтверждено.
7. Цвета слотов из обсуждения: Z #A7BA91, X #91AEBB, C #ACA0BA, V #C69B83. Курки нейтральные. Это предложение, ещё не внесённое в CSS.
