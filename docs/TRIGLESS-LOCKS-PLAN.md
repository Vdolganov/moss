# LOCK ONLY и REPEAT · 0.6.5-dev

**Русский** · [English](TRIGLESS-LOCKS-PLAN.en.md)

Реализовано в нативной экспериментальной сборке RG35XX/Windows. Этот документ заменяет прежний план; стабильная 0.5.2 и браузерный прототип остаются отдельными версиями.

## Локи без ноты

Поставь на шаге 1 ноту с LENGTH 16. На пустом шаге 8 открой VOICE LOCKS или FX LOCKS и измени параметр обычным жестом кнопка + стрелки. Появится **LOCK ONLY**: полый ромб и надпись LOCK. Событие не вызывает noteOn, не обнуляет огибающую и не продлевает LENGTH. NOTE / VELOCITY / LENGTH показывают `-- / NO NOTE`; PROB остаётся доступным.

Каждый параметр удерживает своё последнее значение до следующего события этого параметра или новой ноты. Непомянутые параметры сохраняются. **`--` — отсутствие события; RESET — возврат к базе дорожки.** На новой ноте отсутствующие локи начинают с базы.

Для отдельного RESET уменьши лок до минимума и нажми ещё раз. Следующее уменьшение даёт `--`; увеличение из RESET возвращает минимум. В OPTIONS есть **RESET CURRENT LOCK BANK** (вернуть четыре поля к базе) и **CLEAR CURRENT LOCK BANK** (удалить четыре события). Удаление последнего лока/REPEAT возвращает LOCK ONLY в пустое состояние.

OPTIONS также содержит **REMOVE NOTE / KEEP LOCKS**, **ADD NOTE / KEEP LOCKS**, **CLEAR SELECTED STEP**. Короткое A переключает наличие ноты. Обычное выключение NOTE оставляет сохранённые локи неактивными; редактирование лока на пустом шаге активирует LOCK ONLY. Изменения поддерживают UNDO, который останавливает транспорт.

## TIMING и REPEAT

Вкладка CYCLE стала **TIMING**, четыре поля слева направо:

| RG35XX / Windows | Поле | Область |
|---|---|---|
| Y / Z | CYCLE | Число клеток дорожки |
| B / X | STEP | Разрешение дорожки 1/8–1/64 |
| A / C | REPEAT | Аудио всей дорожки на выбранном шаге |
| X / V | TYPE | EMPTY / NOTE / LOCK ONLY |

REPEAT выбирает **`--`, OFF, 1/8, 1/16, 1/32, 1/64**. Это длительность фрагмента, не число повторов: при 120 BPM 1/16 = 125 ms, 1/64 = 31.25 ms. После события первый следующий фрагмент звучит и записывается в буфер, затем повторяется. Исходный голос продолжает работать под ним. Повтор расположен **перед эффектами**; хвосты delay/reverb сохраняются. Короткие переходы на стыках и при включении/выключении снижают щелчки.

Повтор держится до OFF, новой ноты без собственного REPEAT, остановки или смены секвенции. Он может продолжить звучать после окончания исходной ноты. **`--` не выключает повтор**: поставь следующий LOCK ONLY с REPEAT OFF. Повторное явное значение, даже такое же, захватывает новый фрагмент; изменение BPM также запускает новый захват. Probability проверяется один раз на событие, не на каждый оборот аудио.

Демо **LOCK STUDY**: одна нота LENGTH 16 при разрешении 1/8; CUTOFF на шаге 8; REPEAT 1/16 на 9, 1/64 на 11, OFF на 13; CUTOFF RESET на 14; лок ORBIT на 15.

## Область действия и ограничения

- GRANULAR: CUTOFF/LEVEL плавно меняют облако. SIZE/PITCH/SCATTER/STEREO/границы/окно зерна действуют на новые рождения; начавшиеся зёрна сохраняют параметры. POSITION явно перемещает головку, не перезапуская ноту или активные зёрна.
- MONO / ORGANISM / FM: меняются целевые параметры существующего голоса, сохраняются фазы, огибающая и срок ноты.
- SAMPLER: VOICE LOCKS относятся к выбранной ячейке. Высота, границы и уровень меняются без обнуления возраста; если новые границы исключили текущую позицию, ваншот заканчивается вместо прыжка к началу. FX/REPEAT общие для всех ячеек дорожки. Новая нота любой ячейки сбрасывает общие FX/REPEAT, но не голосовые локи других ячеек. Вероятность локов ячейки и отдельного общего шага независима.
- Без активного голоса VOICE LOCKS не создаёт звук. FX LOCKS может менять существующий хвост. REPEAT на пустом входе до FX захватывает тишину.
- STOP, смена инструмента, секвенции или SONG-слота очищают временное состояние. START после STOP начинает секвенцию сначала. Разные длины циклов и разрешения используют общую сетку 1/64.

## Файлы и проверка

Сохранение — **MS11**, читаются MOS5–MOS9 и MS10. Прежние выключенные шаги с локами остаются выключенными; REPEAT отсутствует. Загрузка сама не переписывает файл. После сохранения в MS11 сборки 0.6.4 и старше файл не откроют. Эксперимент устанавливается отдельно с предварительной резервной копией.

REPEAT использует четыре фиксированных стереобуфера по 96000 кадров int32, около **2.93 MiB** суммарно. На устройстве фрагмент занимает не более секунды на дорожку. В аудио нет файловых операций и выделения памяти. Лимиты дорожек/голосов/эффектов сохранены.

Функциональные проверки сравнивают позиции, возраст, огибающие, срок ноты и счётчики запусков; также проверены RESET, вероятность, полиритмы, SONG, FX-хвосты, физические жесты и миграция. [Отчёт нагрузки и хеш сборки](TRIGLESS-REPEAT-v1.md).
