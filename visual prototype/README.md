# MOSS visual prototype · v0.6

**Русский** · [English](README.en.md)

Это отдельный браузерный прототип без звука. Управление и ограничения нативной 0.5.2 описаны в [её руководстве](../native/prototype/README.md).

Браузерный прототип без аудиодвижков. Откройте START.cmd либо index.html. Для разработки: `node server.cjs`, затем http://127.0.0.1:4173.

## Гранулярный этюд · выбран LENS

Откройте отдельный [granular.html](granular.html): «Срез / Поле / Линза» показывают одно облако с общими настройками. **13 ноября 2026 выбрана Линза / LENS** для нативного инструмента; все три вида остаются доступны. Этюд без звука, с синтетической волной, демонстрационными источниками и отдельным хранилищем; он не меняет проекты основного прототипа.

Здесь Z/X/C/V соответствуют **Y/B/A/X** устройства. Удержание со стрелками меняет четыре поля, Q/E — PLAY/SCAN/TEXTURE, короткое **C / A — FREEZE**, Space — движение, Q+E — опции, Esc — отмена, Ctrl+Z — Undo. Можно выбрать поле мышью и менять стрелками; режим «Без анимации» сохраняет читаемую схему. Переключение вида сохраняет настройки, перезагрузка восстанавливает их с остановленным транспортом.

Рабочий нативный GRANULAR описан в [отдельном руководстве 0.6.1-dev](../docs/GRANULAR-INSTRUMENT.md). У него короткое **X / V — FREEZE**, а **A / C — прослушивание или назначение**; управление этюда не заменяет нативное.

## Структура

- **ATLAS:** только выбор и создание проекта. После открытия проекта сверху ровно GRID / MIX / TAPE.
- **Проект → GRID:** список дорожек с VOICE и SPACE. Выбор дорожки открывает её редактор. В обзоре нет редактирования шагов, микшера или глобальных эффектов.
- **Дорожка → PATTERN / VOICE / SPACE:** паттерн с постоянными параметрами выбранного шага снизу; инструмент ORGANISM/MONO/SAMPLER; независимые эффекты ORBIT/POND/CRUSH дорожки.
- **Проект → MIX → LEVELS / MASTER FX / SCENES:** микшер, эффекты на сумме всех дорожек и сцены.
- **Проект → TAPE:** ресэмплинг одной дорожки с её SPACE или всего проекта, сохранение в память сэмплов.

Проект и дорожка управляются через Q+E → PROJECT / TRACK: переименование, копирование, удаление.

## Единое управление параметрами

Удерживайте **Z / X / C / V** (A / B / X / Y устройства) для первого / второго / третьего / четвёртого параметра текущего экрана. Не нужно предварительно выбирать поле. Подписи у значений показывают назначения; нижняя строка показывает навигацию.

| Экран | Z | X | C | V |
|---|---|---|---|---|
| STEP | Note | Velocity | Length (шаги) | Probability |
| VOICE LOCKS — ORGANISM | Tension | Drift | Chaos | Density |
| VOICE LOCKS — MONO | Cutoff | Resonance | Attack | Release |
| VOICE LOCKS — SAMPLER | Pitch | Start | End | Level |
| VOICE — ORGANISM / MONO | Те же четыре параметра, что в LOCKS | | | |
| VOICE — SAMPLER | Pitch | Start | End | Level |
| SPACE / MASTER FX — ORBIT | Time | Feedback | Mix | Spread |
| SPACE / MASTER FX — POND | Size | Decay | Damping | Mix |
| SPACE / MASTER FX — CRUSH | Drive | Bits | Rate | Mix |
| FX LOCKS | Четыре параметра выбранного эффекта дорожки | | | |
| CYCLE | Length 1–64 | — | — | — |
| MIX — выбранная строка | Level | Pan | Mute | Solo |
| TAPE SOURCE | Source | Length | — | — |
| TAPE EDIT | Start | End | Fade in | Fade out |

С зажатой кнопкой ←/→ меняют число на единицу, ↑/↓ крупно (ноты: октава). Удержание стрелки ускоряет число после 0.6 и 1.6 секунды. Для списков стрелки выбирают соседнее значение, для ON/OFF — включают вправо/вверх и выключают влево/вниз. Границы не зацикливаются. Отпускание кнопки завершает жест; Tab или Escape отменяет его, Ctrl+Z отменяет весь завершённый жест. Фокус не перемещается к редактируемому полю.

В PATTERN выберите шаг. Нижние вкладки STEP / VOICE LOCKS / FX LOCKS / CYCLE переключают банк. STEP содержит четыре свойства шага; CYCLE — длину 1–64 для этой дорожки и паттерна A–D (Z + стрелки, пресеты 16/32/64). Длина ноты LENGTH в STEP меняется C + стрелки: для дрона на 16 шагов включите первый триггер и задайте LENGTH 16. В VOICE LOCKS «—» означает наследование значения инструмента; первая стрелка создаёт lock и включает триггер. Само удержание и переключение вкладки ничего не назначают. OPTIONS → CLEAR CURRENT LOCK BANK очищает текущий банк. FX LOCKS соответствует одному активному слоту SPACE: тип меняется в SPACE → Q+E → EFFECT. Локи других типов сохраняются отдельно. Базовые параметры инструмента и соседние шаги не меняются.

В MIX сначала выберите строку дорожки стрелками или наведением на её параметр; выбранная строка подсвечивается. В TAPE Z+стрелки перебирают MASTER и дорожки, X+стрелки меняют длину. Во время захвата оба параметра заблокированы. Темп в шапке редактируется при фокусе на нём через Z+стрелки.

Короткие нажатия без стрелок: Z — действие/триггер, X — назад, C в PATTERN — шаг ↔ поля, V в PATTERN — STEP → VOICE LOCKS → FX LOCKS → CYCLE. Удержание без стрелок не запускает короткую команду. Нажатие Escape всегда доступно для возврата или отмены.

| Клавиши | Действие |
|---|---|
| Стрелки | Навигация; с Z/X/C/V — изменение параметра |
| Enter | Действие |
| Q / E | Предыдущий / следующий видимый объект |
| [ / ] | Вкладки внутри дорожки; разделы вне неё |
| Space | Визуальный транспорт |
| Tab | Отменить жест/меню, иначе ATLAS |
| Ctrl+Z | Отменить изменение |

Модальные окна остаются для выбора инструмента/сэмпла, ввода названий и подтверждений; числа и источник ресэмплинга редактируются на месте.

## TAPE и SAMPLER

Выберите SOURCE и LENGTH и нажмите CAPTURE. FINISH или окончание захвата открывает черновик EDIT; DISCARD отменяет захват. SAVE сохраняет фрагменты в общую библиотеку. В SAMPLER файл назначается клавише, а Pitch / Start / End / Level меняются независимо для каждого назначения. Исходник режется только явными командами TAPE.

Проекты, общая библиотека и черновики хранятся в браузере; экспорт содержит метаданные используемых файлов. Реального аудио и записи WAV пока нет.

## Сохранение и проверки

Старые проекты v0.1 автоматически дополняются независимыми SPACE, настройками capture и памятью TAPE; шаги и старые сэмплы сохраняются. Сцены сохраняют track SPACE и master FX, но не откатывают библиотеку сэмплов. Хранилища file:// и localhost разные; перенос через JSON.

`node --test model.test.cjs` — 10 проверок, включая миграцию, независимость эффектов и сохранение сцен. `?test=1` использует отдельное хранилище. Экран 640×480; длинные списки прокручиваются. Предел: 8 дорожек, 4 паттерна, 4 сцены. Физическая RG35XX ещё не проверялась.

## TAPE и SAMPLER v0.4

SAMPLER больше не нарезает звук на сегменты. Выберите клавишу, назначьте сэмпл и вручную двигайте START (X + стрелки) и END (C + стрелки) на схематической волне. Z меняет PITCH, V — LEVEL. Начало и конец не пересекаются. Настройки независимы для каждой клавиши, даже если исходник один. ONE SHOT игнорирует gate, GATE и LOOP используют его. PATTERN перебирает только клавиши с доступными файлами; снятое назначение отображается как UNASSIGNED, отсутствующий файл — MISSING FILE.

TAPE разделён на SOURCE / EDIT / LIBRARY. Импорт PCM16 WAV читает только заголовки, без декодирования звука. Новый источник всегда имеет один фрагмент; нарезка выполняется только явными командами SPLIT или + CUT. START / END задают границы вручную. SAVE SLICE и SAVE ALL добавляют отдельные записи в общую библиотеку. Исходник не изменяется.

Библиотека общая между проектами. Сценам принадлежат назначения и параметры клавиш, но не копии файлов. Экспорт v2 включает проект и метаданные используемых сэмплов; импорт создаёт независимые идентификаторы. Сохранение v1 мигрирует в moss.v2, оригинал moss.v1 не перезаписывается. Временная сессия ?test использует отдельное хранилище.

Лимиты для проверки UX: 1 MiB PCM16 на сэмпл, 8 MiB на активный паттерн; это предварительные бюджеты, не измерения GarlicOS. Общий исходник у нескольких клавиш учитывается один раз. Подрезка внутри SAMPLER не уменьшает размер исходного файла в RAM: для этого сохраните короткий фрагмент через TAPE.

Звука, реального ресэмплинга и записи нарезанных WAV пока нет. Библиотека хранит метаданные; волна схематическая. Исходный WAV не копируется в браузерное хранилище.

Проверка: node --test model.test.cjs samples.test.cjs sequencer.test.cjs visual.test.cjs. Дополнительно проверены браузером ручные границы, независимые клавиши, sparse KEY, locks, ONE SHOT, WAV import, сохранение/перезагрузка и выход из capture.
