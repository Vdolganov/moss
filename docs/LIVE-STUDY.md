# LIVE — игра и запись: три варианта интерфейса

**Русский** · [English](LIVE-STUDY.en.md)

Это работающий **браузерный эскиз без звука**, не функция нативной версии 0.13.1. Сначала выбираем визуальный вариант, затем переносим его в приложение.

Запуск: `visual prototype/current/START.cmd`, затем **LIVE · три варианта игры и записи** над экраном. Прямая страница при запущенном сервере: [LIVE](http://127.0.0.1:4174/live.html).

## Три композиции

| Вариант | На что обращает внимание |
|---|---|
| Пульт | Крупные кнопки в физическом расположении, текущая нота и компактный грид |
| Партитура | Нотные строки, длительности и точные смещения относительно сетки; схема клавиш снизу |
| Петля | Цикл дорожки по кругу, длительности дугами; кнопки по бокам, грид снизу |

Три варианта используют один эскиз: переключение композиции не очищает запись. Все остаются монохромными и рассчитаны на 640×480. Подсветка кнопки означает удержание; курсор показывает воспроизведение.

По умолчанию открывается **Партитура** — текущий предпочтительный вариант. Под нотными строками находится цельная крестовина и крупные круглые кнопки в расположении RG35XX: X сверху, A справа, B снизу, Y слева. Окончательный выбор перед переносом в приложение ещё предстоит.

## Предлагаемое управление

| Действие | Anbernic | Компьютер |
|---|---|---|
| Восемь нот | ← ↓ → ↑ / Y B A X | ← ↓ → ↑ / Z X C V |
| Пуск / стоп | START | Space |
| Включить / выключить запись | SELECT + START | Tab + Space |
| Метроном | SELECT + R1 | Tab + E |
| Выбрать дорожку | L2 / R2 | [ / ] |
| Октава ниже / выше | L1 / R1 | Q / E |
| Отменить дубль после записи | L1 + R1 | Q + E |
| Выйти из LIVE | MENU коротко | Escape |
| Вернуть клавиатуру браузеру | — | Shift + Tab |

Сначала кликни по экрану. Играть можно и со стопа. Запись со стопа запускает цикл с начала; во время воспроизведения начинается сразу, без перезапуска секвенции. Повторная комбинация выключает запись, сохраняя транспорт. Восемь кнопок целиком отданы нотам, поэтому обычные A/B и SELECT+стрелки здесь не открывают меню и не меняют BPM.

Общая тональность и скейл принадлежат секвенции. До восьми нот: например C3 D3 Eb3 F3 / G3 Ab3 Bb3 C4. Пентатоника с повтором тоники занимает шесть кнопок; две оставшиеся выключены. Изменение скейла не транспонирует ранее записанные ноты. Играть предполагается инструментом выбранной дорожки, без увеличения его полифонии.

## Что можно проверить сейчас

- Удержание клавиши записывает длительность, нажатие — точное начало между шагами. Нота через границу петли остаётся одним событием.
- REC можно включать и выключать во время цикла. Пока REC включён, дорожка зафиксирована, чтобы случайно не отправить дубль в другой инструмент.
- После записи доступны отмена и квантизация. Настройки находятся в раскрываемом разделе браузерной оболочки, вне LIVE.
- Квантизация начала: 1/8, 1/16, 1/32, 1/64, сила 50/100%. Длительность остаётся живой. Исходное начало хранится отдельно, повторная обработка не накапливает ошибки округления.
- Есть пример с живыми смещениями, очистка с отменой, циклы 15/16/32/64/76/128 шагов и сохранение эскиза JSON. Черновик сохраняется отдельно в браузере и не изменяет проекты MOSS.
- Вид **16 / до 64 шагов** меняет масштаб, сохраняя длину паттерна. Страницы переключаются автоматически по позиции воспроизведения. Пример на 76 шагов показывает две страницы: 64 + 12; пример можно отменить.
- Метроном включается кнопкой оболочки, нажатием MET на экране или Tab+E. В прототипе он визуальный: четыре доли и акцент первой. Доли следуют общему BPM, независимо от цикла выбранной дорожки. Настройка сохраняется. В приложении щелчок будет только в выходе для прослушивания, без попадания в ресэмплинг.
- Смена октавы не обрывает удерживаемую ноту: её подпись и записанная высота сохраняются до отпускания. Партитура показывает реальные высоты; HIGH/LOW сообщает о записанных нотах вне видимых восьми строк.
- При потере фокуса окна прототип отпускает клавиши и останавливает транспорт/запись. Если память браузера недоступна, можно выгрузить JSON.

## Перед переносом на Anbernic

Нужно отдельно проверить задержку игры: текущий аудиоблок длится 32 мс, а общая задержка зависит также от очередей и устройства. Красивый отклик подсветки не доказывает пригодность звукового тракта для живой игры.

Нельзя просто округлять живой ввод до существующих шагов: быстрые ноты внутри одной клетки потеряются. Нужны ограниченный по памяти список событий с точным временем, новая версия сохранения и редактирование таких событий в GRID. Квантизация нативной версии должна учитывать SWING без двойного применения смещения. Локи и старые события должны сохраняться; при наложении дублей нужен явный порядок приоритета.

Лимиты DSP сохраняем: четыре дорожки, прежнее число голосов и гранул, два эффекта на дорожке и мастере. SAMPLER в первом мелодическом варианте может играть выбранный заранее слот по скейлу; режим четырёх барабанных пэдов — отдельная раскладка, не восемь новых назначений.

Подробный контракт, ограничения и этапы: [LIVE interaction proposal](../design/current/live-study.md). В этой итерации код аудиодвижка и установка на устройстве не менялись.
