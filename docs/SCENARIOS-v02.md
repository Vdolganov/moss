# Сценарии v0.2 (заменяют маршруты v0.1)

1. **Новая дорожка:** ATLAS → открыть/создать проект → GRID → + TRACK → MONO. PATTERN → шаг → Z. C переводит фокус к NOTE; удерживать Z и менять стрелками. C возвращает фокус к шагу.
2. **Инструмент и эффекты:** внутри дорожки VOICE → CUTOFF → Z+стрелки. SPACE → FX ON → FEEDBACK → Z+стрелки. Q/E меняют дорожку с независимыми эффектами.
3. **Locks:** PATTERN → шаг 45, снизу видны Bb3, probability80 и cutoff1400. Выбрать cutoff → Z+стрелки. + LOCK добавляет другой параметр; V на параметре VOICE также создаёт lock.
4. **Master FX:** Проект → MIX → MASTER FX. Изменение обрабатывает сумму дорожек и не меняет их SPACE. LEVELS содержит level, pan, mute, solo.
5. **Ресэмплинг:** Проект → TAPE → SOURCE → DRONE. CAPTURE → FINISH. Запись в памяти, DRONE остаётся ORGANISM. Повторить с MASTER. ASSIGN TO TRACK → DUST: открывается VOICE/SAMPLER с новой записью.
6. **Сцены:** MIX → SCENES → сохранить A. Изменить VOICE, track SPACE, MASTER FX; сохранить B. При переключении память TAPE не откатывается.
