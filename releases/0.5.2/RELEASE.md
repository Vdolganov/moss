# MOSS 0.5.2

Первый опубликованный стабильный снимок MOSS для оригинальной Anbernic RG35XX. Версия проверена на GarlicOS 1.4.9 и подтверждена пользователем после обычного запуска и работы.

## В этой версии

- Четыре дорожки: MONO, ORGANISM, FM и SAMPLER с четырьмя назначаемыми сэмплами на экземпляр.
- Независимые циклы и разрешение дорожек, вероятность, длительность нот, локи инструментов и эффектов.
- ORBIT, POND, CRUSH и REEL: до двух активных эффектов на дорожке и мастере.
- TAPE: импорт WAV, предпрослушивание длинного исходника, ручная нарезка, имена сэмплов и внутренний ресэмплинг.
- SONG: до 64 слотов, общий BPM, повторы и длина слота в тактах; создание независимых вариаций секвенций.
- Точное и крупное изменение параметров четырьмя кнопками; перелистывание страниц через R1 + стрелки; видимые вкладки MIX.

Исходники соответствуют тегу `v0.5.2`; архивы Source code формируются GitHub из этого тега. В поставке только три оригинальных тестовых WAV; личные проекты и сторонние сэмпл-паки не включены.

## Установка

Для новой установки скопируйте `Roms` из GarlicOS-архива в `Roms` на карте и запустите **Consoles → APPS → MOSS**. Это приложение, а не образ прошивки. При обновлении сохраните свои проекты, сэмплы, библиотеку, исходники и записи; тестовые WAV из пакета не должны заменять пользовательские файлы с теми же именами.

Windows-архив распакуйте целиком в доступную для записи папку и запустите `MOSS.exe`.

## Проверка

Повторная сборка при подготовке публикации прошла восемь наборов нативных тестов. ARM-бинарник побайтово совпал с аппаратно проверенной сборкой:

`e22b6a3da14a8ae88a4d4db7015ad5760374d96ce78ae6c3bd0bdaaac473c942`

На RG35XX при штатных 1.008 GHz, 32 кГц и блоке 1024 стереофрейма ранее выполнены:

- 180 секунд SONG с 32 уникальными секвенциями, 64 слотами и переходом каждую секунду: максимальный аудиоблок 22.596 мс из 32 мс.
- 60 секунд четырёх ORGANISM с POND + REEL на всех дорожках и мастере: максимум 21.457 мс.
- В обоих прогонах — ноль зарегистрированных превышений аудиобюджета, поздних интервалов и медленных кадров; фоновые захват и сохранение включены.

Это результаты указанных сценариев, а не гарантия всех возможных нагрузок. [Полные условия и ограничения испытаний](https://github.com/Vdolganov/moss/blob/v0.5.2/docs/NATIVE-VERIFICATION-052.md).

GarlicOS 1.3.9 остаётся целью совместимости, но сборка 0.5.2 на ней не перепроверялась. Другие модели RG35XX не проверены. Гранулярный инструмент в этот релиз не входит.
