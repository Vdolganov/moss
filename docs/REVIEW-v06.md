# MOSS v0.6 — проверка

29 автоматических тестов: старые проекты и сцены, все длины 1–64, независимые циклы и паттерны, сохранение скрытых шагов, RAM по активной длине, CRUSH и группы FX-локов, отказ на повреждённых данных, границы и реакция технических графиков.

Браузер: отдельное тестовое хранилище, создание SLOW SIGNAL, LENGTH 16 для ноты, пресеты 16/32, произвольный цикл 31 и 15, соседняя дорожка остаётся со своей длиной, редактирование CRUSH кнопками, локи DRIVE/BITS, смена CRUSH → POND → CRUSH, восстановление прежних локов, перезагрузка. Экран 640×480, содержимое 358/358 px без внутреннего переполнения в FX LOCKS. Ошибок JS не обнаружено.

Ограничения: интерфейс без аудио; один FX-слот дорожки плюс один master FX; 1–64 шага на дорожку и слот A–D. Очередь сцен следует master cycle проекта. Сэмплы — метаданные. Проверка GarlicOS/ARM и аудиобюджета остаётся этапом рабочего движка.
