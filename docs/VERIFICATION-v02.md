# Проверка v0.2 · 10 ноября 2026

Модель: 9/9 тестов, синтаксис app.js проверен. Дополнительно покрыты миграция v0.1, независимость эффектов, сохранение памяти при смене сцены, отказ на неверном FX/sample.

В браузере проверено:

- ATLAS содержит GRID/MIX/TAPE; GRID — только дорожки с VOICE/SPACE; дорожка открывает PATTERN/VOICE/SPACE.
- Z+→ меняет cutoff650→651 без диалога. Удержание Z+→1800ms изменяет651→741; Ctrl+Z возвращает651 одним действием.
- Z+стрелка+X отменяет текущий жест; после отпускания нет зависшего режима редактирования.
- SPACE второй дорожки feedback52; первая дорожка42; MASTER FX42 — значения независимы.
- Шаг45 PULSE показывает Bb3, probability80, cutoff lock1400. Lock inline1400→1401, Ctrl+Z→1400.
- TAPE захватывает DRONE в память, DRONE остаётся ORGANISM. Затем захватывает MASTER. После перезагрузки записи остаются.
- ASSIGN TO TRACK назначает MASTER-запись DUST и открывает SAMPLER.
- PATTERN и MASTER FX помещаются в доступные354px контентной области. В проверенных сценариях console errors отсутствуют.
- Исправлен конфликт mouse hover и keyboard focus при перерисовке: только реальное pointermove меняет hover-выбор шага.

Независимый просмотр кода не нашёл блокирующих дефектов в новых жестах, разделении эффектов, ресэмплинге и миграции. Звук и физическая RG35XX остаются за пределами визуального прототипа.
