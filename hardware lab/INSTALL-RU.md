# MOSS LAB — первый тест на GarlicOS 1.3.9

Пакет **0.1.3** для оригинальной RG35XX. Диагностика экрана, кнопок, звука, памяти и SD. Теперь добавлен тест настоящих WAV-файлов с карты; полного музыкального движка пока нет.

## Проверка сэмплов — версия 0.1.3

Звук и удержания версии 0.1.2 пользователь подтвердил на консоли. Новый SAMPLE ещё нужно прослушать на устройстве.

1. С INPUT нажми **L2 один раз** — откроется SAMPLE (пятая вкладка).
2. **L1/R1** выбирают CHIME, AIR или DUST. **START** читает WAV с карты и запускает звук; повторный START останавливает. Сначала проверь все три в режиме ONCE.
3. Удерживай кнопку и нажимай стрелки: **A — PITCH** (−24…+24 полутона), **B — START**, **X — END** (проценты файла), **Y — MODE** (ONCE / LOOP / THREE). START всегда меньше END. Удержание стрелки ускоряет изменение числовых значений.
4. Изменение параметра или файла останавливает звук. Чтобы услышать новое значение, снова нажми START. Проверь START 20 / END 80, затем петлю LOOP.
5. THREE — три одновременных зацикленных голоса одного загруженного файла: основной питч, −5 и +7 полутонов. Все голоса используют общий буфер. Это тест воспроизведения, не замер полноценного трёхдорожечного проекта с эффектами.
6. LOOP и THREE автоматически заканчиваются через 10 секунд. ONCE заканчивается вместе с выбранным участком, но также ограничен 10 секундами.
7. После прослушивания коротко **A — слышно**, **B — тишина**, **X — щелчки**, **Y — снять оценку**. Удержание кнопки со стрелкой не выставляет оценку.
8. Частота вывода и буфер берутся из AUDIO: сначала 44.1 kHz / 1024 frames; затем можно проверить 48 kHz и 512 frames. Поле OUT на AUDIO относится только к тестовому тону: сэмплы всегда выводятся в стерео (mono дублируется).
9. Для сохранения и выхода удерживай **MENU 2 секунды**. Выключи консоль и подключи карту: отчёты останутся в `MOSS-LAB/reports`.

В комплекте три оригинальных тестовых WAV: CHIME — mono 44.1 kHz / 0.75 s, AIR — stereo 48 kHz / 0.8 s, DUST — mono 22.05 kHz / 1 s. Вместе 263 982 байта. Они создаются скриптом `scripts/make_samples.py`.

Загрузчик принимает только RIFF WAV PCM16, mono/stereo, 8–96 kHz, до 256 KiB звуковых данных на файл и до 512 KiB файла целиком. В памяти один фиксированный PCM-буфер 256 KiB. Чтение SD происходит до запуска звука; в аудиопотоке нет работы с файлами и выделения памяти. Питч использует линейную интерполяцию; короткое сглаживание краёв не заменяет будущий полноценный редактор бесшовных петель.

Отчёт содержит параметры сэмпла, размер PCM, время загрузки, число голосов и переходов петли, число/длительность callback, память процесса и ручную оценку звука. Показатель LATE не является аппаратным счётчиком выпадений. Максимум 32 звуковых запуска (тон и сэмплы вместе) за сеанс.

## Перенос на карту

1. Выключи консоль и подключи SD к компьютеру.
2. Распакуй архив. Открой на карте раздел с существующей папкой `Roms`.
3. Скопируй **содержимое `Roms/APPS` из архива** в `Roms/APPS` на карте. Если `APPS` нет, создай её. Сохрани две соседние сущности:

```text
Roms/
  APPS/
    MOSS-LAB.sh
    MOSS-LAB/
      moss-lab
      README.txt
      verification.json
      samples/
        chime.wav
        air.wav
        dust.wav
      reports/
```

Не создавай вложенность `Roms/Roms`. При двух картах можно использовать карту с ROMs: launcher находит приложение относительно самого себя. Не копируй пакет в MISC; обновлять GarlicOS не требуется.

4. Безопасно извлеки карту, вставь в консоль и включи её.
5. Открой **Consoles → APPS → MOSS-LAB**. Путь `Roms/APPS` также используется для приложений в [инструкции GarlicPress](https://github.com/prosthetichead/GarlicPress#enabling-adb).

## Управление

| Кнопка | Действие |
|---|---|
| L2 / R2 | Предыдущая / следующая вкладка |
| A / B / X / Y + стрелки | Изменить соответствующий цветной параметр |
| Вверх / вправо | Увеличить |
| Вниз / влево | Уменьшить |
| Удержание стрелки | Ускоренное повторение |
| SELECT, коротко | Сохранить текущий отчёт |
| MENU, удерживать 2 секунды | Сохранить отчёт и выйти |
| START + SELECT, удерживать 2 секунды | Дополнительный выход |

Вкладки переключаются задними курками **L2/R2**, а не L1/R1. Короткое MENU на INPUT можно проверить без выхода.

В заголовке должно быть **0.1.3**. Внизу INPUT счётчик LIVE показывает, что приложение продолжает работать, RAW — число входящих событий. Если RAW растёт, но кнопка не подсвечивается, её событие будет записано в журнал. Вне звукового теста отчёт дополнительно сохраняется раз в 15 секунд.

## Проверка за несколько минут

**Короткая повторная проверка 0.1.2.** На INPUT удерживай A: должна оставаться подсветка и расти HOLD. Не отпуская A, зажми вправо на 1–2 секунды — значение должно увеличиваться с ускорением. Затем попробуй влево. Все четыре тестовых значения теперь начинаются с 50; на границах появляются MIN/MAX. На AUDIO один раз нажми START и подожди: прогресс и CALLBACKS должны расти, тон длится 10 секунд и по умолчанию идёт в оба канала (BOTH).

**INPUT.** Нажми и отпусти каждую кнопку: BUTTONS должен дойти до 15/15. L2/R2 меняют вкладку — вернись на INPUT для продолжения. По очереди удерживай A, B, X и Y, нажимая каждую из четырёх стрелок: CHORDS должен дойти до 16/16. Подержи стрелку — изменение значения ускорится. Нажми L1+R1 вместе: появится OK. После отпускания кнопки не должны оставаться зажатыми на экране.

**AUDIO.** Начальные параметры: 44.1 kHz, 1024 frames, BOTH, 440 Hz. Выставь комфортную громкость обычными кнопками консоли. START запускает тихий тон на 10 секунд; повторный START завершает его с fade. В ALT по две секунды чередуются левый, правый и оба канала; для различения каналов нужны стереонаушники.

После прослушивания коротко нажми **A — слышно нормально**, **B — тишина**, **X — щелчки**, **Y — убрать оценку**. Это твоя оценка, не автоматический вывод. Удержание A/B/X/Y + стрелки меняет параметры и не выставляет оценку.

Попробуй буфер **512**: удерживай B и нажми влево; снова START. По желанию повтори с 256, затем с 48 kHz через A + вправо. Изменение параметров останавливает текущий тест; новый запускается по START. Максимум 32 звуковых теста за сессию.

LATE INTERVALS — интервалы callback дольше 1.5 периода блока, **не** измеренная задержка звука и **не** счётчик аппаратных выпадений. Ошибки аудио записываются в отчёт. Callback не доказывает, что звук слышен.

**DISPLAY.** Проверь рамку, текст и цвета. START включает движение полосы. Отметь разрывы, мерцание, обрезку или поворот изображения. FPS — скорость представления кадров приложения, не подтверждение частоты панели.

**SYSTEM.** Коротко A: запись и чтение собственного временного файла 256 KiB. Ожидаемый результат — VERIFIED. RAM TOTAL и RSS берутся из системы. AVAILABLE = -1 означает, что ядро не публикует этот показатель, а не нулевую свободную память.

Нажми SELECT, затем удерживай MENU две секунды для выхода.

## Что вернуть после теста

В `Roms/APPS/MOSS-LAB/reports` будут:

- `report-...json` — кнопки, сырые события, аудио, память, экран и SD.
- `startup-...log` — журнал запуска и сведения о системе.

Пришли файлы последнего запуска или ZIP всей папки `reports`. Допиши: звук есть/нет, щелчки есть/нет и какие проблемы заметил с экраном/кнопками. Отчёты автоматически никуда не отправляются.

Если приложение сразу вернулось в меню, всё равно нужен `startup-...log`: он создаётся до запуска ARM-файла и поможет найти отсутствующую библиотеку или другую несовместимость. При ошибке загрузчика JSON может не появиться.

Если ни одна кнопка не распознана, LAB выйдет примерно через 60 секунд и оставит отчёт, если запись на карту работает. При полном зависании воспользуйся обычным восстановлением консоли, затем забери сохранившиеся журналы. Если MOSS-LAB не появился в APPS, проверь расположение `.sh` и соседней папки.

LAB пишет только в свою папку. Для удаления убери `MOSS-LAB.sh` и папку `MOSS-LAB` после копирования нужных отчётов.
