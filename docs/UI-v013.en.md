# MOSS 0.13 — native interface

[Русский](UI-v013.md) · **English**

The approved monochrome `visual prototype/current` interface is now implemented for RG35XX and Windows. Synths, effects, WAV processing and the MS18 sequence format are retained. The browser wrapper, pointer interaction and simulated playback remain prototype adaptations.

## Controls

| Action | RG35XX | Windows |
|---|---|---|
| Main tabs; ATLAS SEQUENCES / SONGS | L2 / R2 | [ / ] |
| Visible parameter or local tabs | Tap L1 / R1 | Tap Q / E |
| Sampler slot or TAPE region | L1 + ← / → | Q + ← / → |
| Nested parameter page | L1 + ↑ / ↓ | Q + ↑ / ↓ |
| Grid or list page | R1 + ← / → | E + ← / → |
| Current screen options | L1 + R1 | Q + E |
| Four fields, left to right | Y / B / A / X | Z / X / C / V |
| Fine / coarse adjustment | Field button + ←→ / ↑↓ | Field key + ←→ / ↑↓ |
| SET LOCK / CLEAR LOCK / RESET TO BASE | Field button + MENU | Field key + Esc |
| Confirm / back | A / B | C / X |
| Transport | START | Space |
| Tempo | SELECT + arrows | Tab + arrows |
| Save and exit | Hold MENU for 2 seconds | Hold Esc for 2 seconds |

Use D-pad to select list rows. Holding L1 reveals a hint; releasing a held or used modifier does not also change tabs. Open menus isolate the underlying screen. The name keyboard retains L1/R1 caret movement.

## Changes

- Centered rounded light tabs, faded overflow edges and consistent spacing. Parameter fields sit above the footer. Text roles are 21 / 14 / 12 px, with 8 px reserved for duration captions.
- Monochrome fields show a miniature physical-button diagram, letter, label and value with a compact unit, in Y / B / A / X order.
- GRID defaults to **up to 64 cells** per page. **OPTIONS → GRID VIEW** switches 16 / 64 without altering musical length or division.
- Empty, note, lock-only, selected and playing steps have distinct shapes/fills. Duration lines cross rows and pages. One-shot lines account for file duration, trim, pitch and LENGTH rather than extending past the end of a file.
- Four sampler slots appear above the grid, with activity from actual voices. Select a slot with L1+←/→.
- PATTERN exposes **STEP / V-LOCK / enabled effect LOCKS / TIME**. Each enabled effect gets a tab in chain order; bypass retains stored locks. Counters identify nested pages.
- Individual SET/CLEAR/RESET actions are explicit. Numeric values clamp at their limits. `--` means no lock and `RST` means return to the base value.
- **CLEAR SELECTED HIT** preserves other slots and shared FX/SHIFT/REPEAT. Clearing an entire step or pattern asks for confirmation. Undo follows the last accepted edit, including a complete held gesture.
- TAPE uses monochrome regions, a brighter active part, physical-button labels and an independent preview cursor. MOVE / TRIM / FINE use the shared navigation. Tap a region button to audition; hold it with arrows to edit. Draft metadata is stored separately from prepared WAVs.
- **SAVE KIT** saves to the library; **SAVE SELECTED + ASSIGN SLOT** assigns one imported result; **SAVE KIT + ASSIGN FOUR SLOTS** replaces all four slots. Occupied slots require confirmation. Kit folders support rename; referenced samples are protected from deletion.
- SONG supports duplication and recovery of the last deletion. Empty slots show `--`; the song-wide LOOP remains editable.

## Data and verification

Device projects, library, recordings and the previous binary were backed up before installation. Updating does not replace user WAVs. See the [device and workflow verification](verification/ui-v013/README.md). Short stress runs do not establish indefinite reliability; new issues should be reproduced with the affected sequence.
