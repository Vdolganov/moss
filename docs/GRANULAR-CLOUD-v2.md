# GRANULAR CLOUD — проверка 0.6.1-dev

**Русский** · [English](GRANULAR-CLOUD-v2.en.md) · 13 ноября 2026

Отдельная экспериментальная сборка MOSS-GRANULAR установлена на оригинальную RG35XX с GarlicOS 1.4.9. Стабильный MOSS 0.5.2 не заменён. Перед обновлением сохранены проекты, прежний бинарник и launcher; существующие файлы проектов проверены по SHA256 и не изменены установщиком. Добавлена новая секвенция **LENS CLOUD**.

## Изменения

- SCATTER 100% распределяет рождения зёрен по всей выбранной области независимо от положения якоря, скорости сканирования и FREEZE. Восемь областей выбираются с учётом занятых голосов; внутри области позиция случайная. SCATTER 0% рождает зёрна у якоря.
- Границы чтения, панорама и фейды фиксируются для каждого родившегося зерна. Перемещение START/END не разрывает уже звучащие зёрна.
- Четыре банка: PLAY, SCAN, TEXTURE, ENVELOPE. В последнем GRAIN IN/OUT задаются в процентах SIZE, NOTE IN/OUT — в миллисекундах. L1/R1 переключают банки.
- Громкость облака учитывает ожидаемое перекрытие и форму окна. LEVEL регулируется отдельно. Выходной monitor gain повышен с 135% до 180% (относительно прежнего +33%); внутренний ресэмплинг остаётся до этого усиления.
- MOS8 хранит 16 параметров и локов. При чтении MOS7 старый FADE становится NOTE IN/OUT; ненулевой JITTER становится SCATTER 100%. Старые JITTER-локи снимаются, поскольку однозначного преобразования миллисекунд в долю области нет. Исходные файлы сохранены в резервной копии.

## Проверка на устройстве

Бинарник SHA256: `a85fa355b408920b17e6bae61f61539244cf8fd4390dab608457ff72f19f7e1b`.

32 кГц, 1024 сэмпла на callback: бюджет **32 мс**. Четыре дорожки, до восьми зёрен на дорожку, два разрешённых эффекта на каждой и два на мастере. POND+REEL, 32 MiB PCM, максимальные паттерны при 1/64, 240 BPM, работающий интерфейс и периодический ресэмплинг.

За **14 минут**: 0 выходов за бюджет, 0 поздних callback, 0 underrun потока и 0 медленных кадров UI во всех пяти профилях. Наихудший измеренный запас — **1.789 мс**: это не большой резерв для новых эффектов и не гарантия для всех будущих изменений. [Исходные отчёты и manifest](verification/granular-cloud-v2/manifest.json).

Host/ARM unit и integration tests пройдены; host UBSan не выявил ошибок. Проверены распределение по областям, независимость полного SCATTER от якоря, границы, огибающие, конечность сигнала, блоковая инвариантность, 16 локов, четыре банка, миграция MOS7 и MOS8 roundtrip. Браузерные тесты — 6/6. Отдельно на консоли открыты LENS CLOUD → VOICE → ENVELOPE и проверено отображение во время воспроизведения; приложение затем штатно закрыто.

Синтетические WAV-примеры проверены численно на конечность и отсутствие предельных PCM значений. Это не слуховая оценка выхода консоли: характер, субъективную громкость и переходы пользователь проверяет в наушниках.

Обычный сеанс открытия UI отдельно записал один поздний интервал callback и один кадр 36.083 мс при максимальной обработке аудио 4.876 мс, без превышения аудиобюджета. В этом сеансе были переходы между проектами и остановка/запуск аудио; журнал не позволяет точно приписать событие одному переходу. Эти показатели не скрыты и не включены в нулевые счётчики пяти нагрузочных профилей.
