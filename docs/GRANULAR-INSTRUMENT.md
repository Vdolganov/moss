# GRANULAR / LENS · 0.8.0-dev

В 0.8.0 добавлена CLOUD: reverse, расстройка, вариация длины и интервалов зёрен. Сохранения — MS14. [Исследование, управление и проверка](AMBIENT-RESEARCH-v08.md).

**Русский** · [English](GRANULAR-INSTRUMENT.en.md)

Один подготовленный сэмпл, до восьми одновременных зёрен на дорожку. Четыре дорожки, по два эффекта на дорожке и мастере. Это отдельный эксперимент **MOSS-GRANULAR**; стабильный MOSS 0.5.2 остаётся отдельно.

## Первое облако

Открой APPS → MOSS-GRANULAR → LENS CLOUD → LENS → VOICE. START запускает секвенцию. Для своего источника: L1+R1 → ASSIGN / REPLACE SAMPLE → готовый сэмпл или + IMPORT FROM DEVICE. Импорт использует ручной выбор START–END в TAPE, имя и сохранение; отмена сохраняет прежнее назначение.

У грануляра одно назначение; четыре ячейки обычного SAMPLER к нему не относятся. Подготовленный PCM16 WAV занимает до **1 MiB**. Границы в VOICE не уменьшают расход памяти: для этого нужно сохранить более короткий файл через TAPE.

## Управление

L1/R1 переключают пять банков. Порядок полей — **Y / B / A / X** (Windows: Z / X / C / V). Удерживай соответствующую кнопку: ←/→ меняют точно, ↑/↓ крупно. Короткое A прослушивает ноту: две длины зерна плюс NOTE IN, минимум 2 и максимум 20 секунд, затем действует NOTE OUT; без источника открывает назначение. Короткое X (Windows V) удерживает якорь сканирования.

| Банк | Y | B | A | X |
|---|---|---|---|---|
| PLAY | SPEED −3…3× | PITCH ±24 полутона | SIZE 1–8000 ms | DENSITY 0–128/s |
| SCAN | POSITION 0–100% | START 0–99.9% | END 0.1–100% | SCATTER 0–100% |
| TEXTURE | STEREO 0–100% | JUMP 0–100% | CUTOFF 20–14000 Hz | LEVEL 0–200% |
| ENVELOPE | GRAIN IN 0–100% | GRAIN OUT 0–100% | NOTE IN 0–9000 ms | NOTE OUT 0–9000 ms |
| CLOUD | REVERSE 0–100% | DETUNE ±0–100 cents | SIZE VAR ±0–75% | JITTER 0–100% |

**SCATTER = 100%** распределяет рождения по всему выбранному диапазону. Восемь областей выбираются в случайном порядке с приоритетом свободных: полное облако не собирается возле одной головки. Позиции внутри областей случайны. При меньшей плотности одновременно может звучать меньше восьми зёрен. Это распределение точек рождения, а не обещание неподвижных равномерных точек чтения: каждое зерно продолжает читать со своей высотой.

**SCATTER = 0%** рождает зёрна точно у якоря. Промежуточные значения задают ширину окна вокруг него в долях START–END; окно оборачивается внутри этого диапазона. SPEED перемещает якорь, POSITION устанавливает его, FREEZE удерживает. При 100% положение маркера, SPEED и JUMP не влияют на распределение рождений: облако охватывает весь диапазон. Маркер остаётся видимым; поля скорости и позиции помечены SCAN ANCHOR.

START/END теперь ограничивают и рождения, и чтение каждого нового зерна. Зёрна, начавшиеся до изменения границ, спокойно заканчивают прежние окна. PITCH задаёт скорость чтения, независимо от SPEED. STEREO закрепляет отдельную панораму за каждым зерном; облако целиком больше не качается из стороны в сторону. **JUMP** заменяет IRREGULAR и задаёт ширину случайного смещения маркера относительно выбранного диапазона. 0% отключает скачки, 100% позволяет перейти в любую часть START–END. Скачки происходят через случайные интервалы 0.75–1.75 секунды; между ними действует SPEED. FREEZE останавливает и ход, и скачки маркера, но не зёрна. Изменение затрагивает будущие рождения; уже звучащие зёрна доигрывают свои участки. Генератор случайных скачков независим от распределения зёрен.

**SIZE — до 8 секунд.** Планировщик ограничивает фактическую частоту рождений величиной `min(DENSITY, 8 / min(8, SIZE_в_секундах × (1 + SIZE_VAR/100)))`, равномерно распределяя голоса во времени. Например, SIZE 8 s даёт максимум одно новое зерно в секунду. Фактическое значение G/S видно слева от Линзы. Плотность не расширяет пул: занятый голос не обрывается, при смене размера существующие зёрна сохраняют прежнюю длину. Повторные ноты не сбрасывают фазу рождения действующего облака. При выходе чтения за END зерно возвращается к START; длинный SIZE не требует более крупного PCM-буфера.

**GRAIN IN / OUT** — отдельные атака и затухание в процентах SIZE, с плавной косинусной формой. Остаток длительности — плато. Например, SIZE 400 ms, IN 10%, OUT 60%: 40 ms атаки, 120 ms плато, 240 ms затухания. Увеличение одного фейда при нехватке места уменьшает другой. Независимые конфликтующие локи пропорционально приводятся к 100%. Даже нулевой фейд оставляет один нулевой отсчёт на краю окна. Параметры окна фиксируются при рождении; текущие зёрна не обрываются.

**NOTE IN / OUT** управляют появлением и отпусканием всего облака. Это отдельная огибающая: LENGTH шага держит ноту, после него действует NOTE OUT. CUTOFF и LEVEL меняются плавно. Усиление учитывает ожидаемое перекрытие и форму окна, вместо постоянного ослабления в восемь раз; оно не анализирует громкость исходника и не является компрессором. LEVEL позволяет согласовать источники. Общий выход приложения поднят с 135% до 180% (+33% к предыдущей версии), с прежним мягким ограничением пиков. Усиление мониторинга не записывается повторно при внутреннем ресэмплинге.

## PATTERN и Линза

C3 при PITCH 0 читает на исходной высоте. VOICE LOCKS содержит все 20 параметров. L1+стрелки выбирают вложенный банк; L1/R1 остаются навигацией STEP / VOICE LOCKS / FX LOCKS / TIMING. `--` не добавляет события параметра; RESET возвращает к базе. Событие POSITION явно перемещает головку.

Круг построен из пиков реального сэмпла в абсолютных координатах источника. Волна вне START–END приглушена, границы обозначены штрихами. Дуга каждого зерна показывает прочитываемый участок с учётом длины, высоты и перехода END → START; заполненный квадрат движется по ней согласно реальной позиции чтения. Яркость дуги следует огибающей зерна. Дорожка дуги остаётся на месте весь срок жизни зерна. Если зерно проходит диапазон целиком, видна вся его дуга и подпись LOOP GRAINS; движение квадрата повторяется по кругу. Контурный квадрат снаружи — общий маркер сканирования. Границы старых зёрен сохраняются до их окончания. Снимки поступают из аудиодвижка, отдельного таймера анимации нет. Без источника — NO SAMPLE / A ASSIGN SAMPLE.

**LOCK ONLY и аудиоповтор REPEAT реализованы в 0.6.5.** Уже звучащая нота сохраняет срок и огибающую. Управление и время действия описаны в [TRIGLESS-LOCKS-PLAN.md](TRIGLESS-LOCKS-PLAN.md).

## Формат и проверка

Сохранение — **MS14**, включая 20 параметров грануляра и восемь параметров POND с локами. MOS5…MS13 читаются. Новые поля CLOUD становятся нулевыми, добавленные локи наследуют базу; живые зёрна сохраняют направление, длину и высоту. Новый POND меняет звучание старых пресетов. Открытие не перезаписывает файл. Сохраняй исходники: прежние версии MOSS не читают MS14. Историческая миграция IRREGULAR/JITTER для ранних файлов сохранена; она не относится к новому CLOUD JITTER.

История проверки облака 0.6.1: [GRANULAR-CLOUD-v2.md](GRANULAR-CLOUD-v2.md). Старый [GRANULAR-NATIVE-v1.md](GRANULAR-NATIVE-v1.md) относится только к 0.6.0-dev. Линейная интерполяция по-прежнему может давать алиасинг при большой транспозиции вверх. Это собственный DSP, не порт кода Mangl.

[Браузерный этюд](../visual%20prototype/granular.html) остаётся без звука и с синтетическими источниками. Он отражает четыре банка и распределение облака, но не заменяет проверку аудио. В этюде короткое C / A включает FREEZE; нативное управление X / V отличается намеренно.

Новые DRIVE/ORBIT, формат MOS9 и проверка 0.6.2: [FX-CHARACTER-v1.md](FX-CHARACTER-v1.md).

Текущая проверка длинных пэдов, JUMP и Линзы: [AMBIENT-LENS-v1.md](AMBIENT-LENS-v1.md). Для начала попробуй SIZE 3200 ms, SPEED 0.12×, JUMP 75%, SCATTER 40%, GRAIN IN/OUT 50/50 и достаточно длинный LENGTH ноты. SIZE не заменяет LENGTH: при короткой ноте облако всё равно отпускается по NOTE OUT.
