# MOSS · контракт управления v0.6

## Иерархия

ATLAS содержит проекты. Открытие проекта ведёт в GRID; внутри проекта три основные вкладки GRID / MIX / TAPE. GRID содержит только обзор дорожек VOICE + SPACE. Открытие дорожки ведёт в PATTERN / VOICE / SPACE. MIX содержит LEVELS / MASTER FX / SCENES; TAPE — SOURCE / EDIT / LIBRARY. Сцена остаётся полным снимком музыкальных данных, включая состав дорожек и все паттерны.

## Кнопки

| Ввод | Поведение |
|---|---|
| L1/R1 · Q/E | Предыдущий/следующий видимый объект; без зацикливания |
| L2/R2 · [/] | Основные вкладки текущего уровня; циклически |
| L1+R1 · Q+E | OPTIONS текущего экрана; одиночное действие ждёт отпускания |
| D-pad | Локальный выбор; без применения сцены/загрузки проекта |
| Z/X/C/V + стрелки | Слот 1/2/3/4; удержание стрелки ускоряет числа |
| A коротко · Z | Действие / триггер / назначение |
| B коротко · X | Меню закрыть, иначе один уровень назад |
| Y коротко · V | STEP / VOICE LOCKS / FX LOCKS / CYCLE либо раздел MIX/TAPE |
| X коротко · C | В PATTERN переключить шаг/поля |
| SELECT · Tab | Отменить жест/меню, иначе ATLAS |
| START · Space | Транспорт; STOP снимает очередь сцены |

## Объект Q/E

ATLAS: проект; GRID/PATTERN/VOICE/SPACE/LEVELS: дорожка; SCENES: слот; TAPE EDIT: слайс; TAPE LIBRARY: файл. MASTER FX, TAPE SOURCE, отсутствие объекта: пара неактивна, footer показывает —. Навигация не изменяет музыкальные данные. В SAMPLER D-pad выбирает клавиши и переходит между диапазонами; Q/E остаётся сменой дорожки.

Приоритет: текст → меню → активный жест → защита выхода CAPTURE → обычная навигация. Во время жеста курки не меняют объект. Q+E не успевает сначала переключить дорожку. Потеря фокуса очищает зажатые курки и останавливает повтор. Меню восстанавливает фокус инициатора. Один жест — один Undo; Undo доступен из OPTIONS и на клавиатуре.

## Объекты и восстановление

TAPE создаёт черновик из WAV заголовков или симуляции захвата. Новый черновик имеет один диапазон; нарезка — только по явной команде. SAVE добавляет metadata-assets в общую библиотеку. SAMPLER хранит независимые назначения assetId/pitch/start/end/level/playMode на клавишах. Шаг выбирает только доступные назначения. Удаление назначения оставляет номер KEY; отсутствующий файл не заменяется соседним.

Выход из CAPTURE: STAY / FINISH / DISCARD. Черновик, проекты и библиотека сохраняются отдельно от навигационных состояний. Старые данные v1 остаются нетронутыми; v2 хранит миграцию. WAV/PCM ресэмплинг, физическая запись слайсов и ARM-производительность ещё не реализованы.

## Состояния

Пустой проект даёт ADD TRACK; пустая клавиша — ASSIGN; пустая LIBRARY — путь к SOURCE. ONE SHOT явно выключает LENGTH ноты. Превышение предварительных лимитов 1 MiB/asset и 8 MiB/активный набор сообщает причину. Ошибки сохранения и импорта не выдаются за успех. Полные исходники и метаданные проекта остаются доступны для экспорта и восстановления.

## Эффекты и локи

SPACE и MASTER FX: ORBIT, POND, CRUSH. Тип выбирается через Q+E → EFFECT, включение отдельно через ENABLE / BYPASS. CRUSH: Z DRIVE 0–100%, X BITS 2–16, C RATE ÷1–32, V MIX 0–100%. RATE уменьшает частоту обновления сигнала, а не высоту ноты. Все четыре поля управляются одинаковым жестом. Графики показывают модель transfer и sample hold, не аудио.

FX LOCKS шага хранит отдельный набор для каждого типа эффекта дорожки. Смена типа сразу меняет четыре поля; прежний набор сохраняется и возвращается при обратном переключении. Нет автоматического включения эффекта при редактировании лока: BYPASS остаётся явно видимым. Пустое значение означает наследование базового параметра. OPTIONS удаляет один лок или текущий банк. Локи мастера к шагам отдельных дорожек не привязываются.

## Длительность и независимые циклы

STEP: Z NOTE/KEY, X VELOCITY, C LENGTH (1–64 шага), V PROBABILITY. Один шаг равен 1/16 ноты при общем BPM. Для дрона в 16-шаговом цикле достаточно триггера на первом шаге и LENGTH 16. Q+E → NOTE LENGTH / TO CYCLE END назначает длительность от выбранного шага до конца цикла и включает триггер. У SAMPLER ONE SHOT длительность задаётся самим сэмплом; для удержания нужен режим GATE/LOOP.

CYCLE: длина 1–64, независимо для каждой дорожки и каждого паттерна A–D. Z + стрелки задаёт любое целое число; видимые пресеты 16/32/64. Сокращение скрывает шаги, не удаляя ноты и локи. Последняя страница дополняется недоступными клетками. Возвращение длины восстанавливает скрытый материал; увеличение проверяет лимит активных PCM. Копирование паттерна и сцены сохраняют длины.

Все дорожки считают общий непрерывный транспорт, но позиция каждой равна tick modulo её длина. Циклы 7 и 15 совпадают снова через 105 шагов; общий цикл проекта не сбрасывает дорожки. Очередь сцены пока использует сохранённый master cycle проекта (16 для нового проекта, 64 у SLOW SIGNAL), указанный в SCENES. Смена сцены или паттерна начинает транспорт с нуля; пауза сохраняет позицию.

Прототип хранит LENGTH и визуализирует его, но не генерирует note-off или звук. Для будущих MONO/ORGANISM следующий успешный триггер должен перезапускать голос; удержание через границу цикла не должно само создавать новый триггер. Точная release/tie-политика проверяется при подключении движка.

## Возможность переноса CRUSH

Простое ограничение амплитуды / waveshaping, квантование разрядности и удержание отсчёта не требуют длинных буферов. Это реалистичный кандидат для C++ на ARMv7, однако CPU-бюджет всей цепочки и качество сглаживания требуют измерений на оригинальной RG35XX. В этом прототипе нет DSP.

Источники алгоритмов: [waveshaper, Bram de Jong](https://www.musicdsp.org/en/latest/Effects/41-waveshaper.html), [bit depth + zero-order hold](https://audio.js.org/modules/effect-bitcrusher/).


## Native 0.2.1 · GRID и глобальный темп

Пользователь подтвердил работу музыкального прототипа 0.2.0 и ambient-банка. В 0.2.1 нативный GRID приведён к списку TRACK / VOICE / SPACE без мини-паттернов. PATTERN использует сетку 8×2, светлые включённые шаги, независимую рамку выбора, playhead, линию длительности, страницу и постоянный инспектор выбранного шага. Пресеты длины доступны через OPTIONS; сокращение цикла сохраняет скрытые шаги.

Нативное уточнение управления: SELECT + стрелки меняет BPM в шапке на любом экране открытого проекта, с ускорением удержания. На Windows это Tab + стрелки. Короткий SELECT остаётся возвратом в ATLAS; в OPTIONS закрывает меню. Удержание SELECT без стрелки не покидает экран. Оба порядка отпускания безопасны: жест не передвигает шаг и не запускает навигацию. Темп меняется без сброса музыкальных часов; один жест — один Undo. MIX: LEVEL / PAN / MASTER / MUTE; CYCLE содержит только длину дорожки. ONE SHOT показывает LENGTH OFF.

Изменения проверены тестами общей логики и музыкального движка, сборками ARM/Windows и просмотром экранов, включая неполную последнюю страницу и удержание SELECT. Физический тест новых жестов 0.2.1 ожидается. Обновление установленной карты сохраняет projects/samples/reports с проверкой контрольных сумм; полный установочный ZIP содержит исходный demo-банк для чистой установки.
