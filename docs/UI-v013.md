# MOSS 0.13 — интерфейс на устройстве

**Русский** · [English](UI-v013.en.md)

Утверждённый монохромный интерфейс `visual prototype/current` перенесён в приложение RG35XX и Windows. Синтезаторы, эффекты, работа с WAV и формат секвенций MS18 сохранены. Браузерная оболочка, мышь и имитация воспроизведения остаются особенностями прототипа.

## Управление

| Действие | RG35XX | Windows |
|---|---|---|
| Главные вкладки; SEQUENCES / SONGS в ATLAS | L2 / R2 | [ / ] |
| Видимые вкладки параметров или локальные вкладки | L1 / R1 коротко | Q / E коротко |
| Слот сэмплера или участок TAPE | L1 + ← / → | Q + ← / → |
| Вложенная страница параметров | L1 + ↑ / ↓ | Q + ↑ / ↓ |
| Страница грида или списка | R1 + ← / → | E + ← / → |
| Опции текущего экрана | L1 + R1 | Q + E |
| Четыре поля слева направо | Y / B / A / X | Z / X / C / V |
| Точное / крупное изменение | Кнопка поля + ←→ / ↑↓ | Клавиша поля + ←→ / ↑↓ |
| SET LOCK / CLEAR LOCK / RESET TO BASE | Кнопка поля + MENU | Клавиша поля + Esc |
| Подтвердить / назад | A / B | C / X |
| Транспорт | START | Space |
| Темп | SELECT + стрелки | Tab + стрелки |
| Сохранить и выйти | MENU, 2 секунды | Esc, 2 секунды |

Строки списка выбираются D-pad. Удержание L1 показывает подсказку; после удержания или сочетания отпускание не переключает вкладку. Открытое меню блокирует изменение фонового экрана. Ввод имени сохраняет привычные L1/R1 для перемещения каретки.

## Что изменилось

- Округлое светлое выделение вкладок, затухание переполнения по краям, единые отступы. Нижние поля закреплены над служебной строкой. Размеры текста 21 / 14 / 12 px; 8 px только для маленьких подписей длительности.
- Четыре поля монохромные: миниатюра физических кнопок, буква, подпись и значение с короткой единицей. Порядок Y / B / A / X.
- GRID показывает до **64 клеток** на странице по умолчанию. **OPTIONS → GRID VIEW** переключает 16 / 64. Это масштаб представления, длина и деление дорожки не меняются.
- Пустой шаг, нота, лок без ноты, курсор и воспроизводимый шаг различаются формой/заливкой. Линии длительности продолжаются через строки и страницы. Для ваншота линия учитывает длину файла, обрезку, высоту и LENGTH; она не обещает звук после окончания файла.
- Четыре слота сэмплера находятся над сеткой; индикаторы звучания следуют реальным голосам. Слот выбирается L1+←/→.
- В PATTERN только **STEP / V-LOCK / включённые эффекты LOCKS / TIME**. У каждого эффекта своя вкладка в порядке цепочки; отключение эффекта сохраняет его локи. Счётчик показывает вложенные страницы.
- Для одного параметра есть явные SET/CLEAR/RESET. Числа ограничиваются диапазоном и не превращаются в RESET при переходе через минимум. `--` означает отсутствие лока, `RST` — возврат к базовому значению.
- **CLEAR SELECTED HIT** не стирает соседние слоты и общие FX/SHIFT/REPEAT. Общая очистка шага и паттерна требуют подтверждения. Undo относится к последней принятой правке, включая весь жест удержания.
- TAPE: монохромные участки, более светлый активный, буквы кнопок и отдельный курсор предпрослушивания; MOVE / TRIM / FINE. Короткая кнопка участка прослушивает его, удержание со стрелкой редактирует. Черновик сохраняется отдельно от готовых WAV.
- **SAVE KIT** сохраняет библиотеку; **SAVE SELECTED + ASSIGN SLOT** назначает один результат из импорта; **SAVE KIT + ASSIGN FOUR SLOTS** заменяет четыре слота. Занятые слоты требуют подтверждения. Папки комплектов можно переименовывать; используемые сэмплы защищены от удаления.
- SONG можно дублировать и восстановить после последнего удаления. Пустой SONG показывает `--` для свойств слота; LOOP остаётся доступен.

## Данные и проверка

Перед обновлением сохранены проекты, библиотека, записи и прежний бинарник устройства. Сборка не заменяет пользовательские WAV. Проверки: [отчёт устройства и сценариев](verification/ui-v013/README.md). Короткие нагрузочные проверки не заменяют длительное использование: новые проблемы стоит воспроизводить на конкретной секвенции.
