# Разбор и проверка v0.5

Метод: экспертный разбор структуры и клавиатурных сценариев, затем технический проход в браузере. Реальные участники не тестировались, метрики удобства не измерялись.

| Найдено | Приоритет | Исправление |
|---|---|---|
| Старые схемы противоречили разделению TAPE/SAMPLER | Высокий | Пять актуальных схем design/current; исторические страницы помечены |
| Q/E меняли скрытую дорожку в MASTER FX/SCENES | Высокий | Явная область объектов, без зацикливания и без применения сцены |
| Дублирование параметров в footer и множество редких кнопок | Средний | Одна подпись каждого слота, Q+E OPTIONS, первичные действия сохранены |
| Графика не объясняла параметры | Средний | Шкалы, единицы, зависимость геометрии от значений, MODEL и временной курсор |
| Зелёный использовался как общий цвет выбора | Средний | Нейтральный графит; четыре цвета зарезервированы за слотами |

## Технические сценарии

- Q+E открывает OPTIONS без смены дорожки; Tab закрывает с восстановлением позиции.
- Q/E выбирают дорожку в VOICE; редактор остаётся на той же вкладке.
- Во время числового жеста E не меняет цель; Tab откатывает весь жест.
- MASTER FX: E не меняет выбранную дорожку LEVELS.
- SCENES: E выделяет B, текущая ARRIVAL остаётся активной; Q+E предлагает SAVE SCENE B.
- STOP удерживает статичную модель; RUN показывает отдельный временной курсор.
- Сохраняются ручные START/END SAMPLER, импорт WAV, общая библиотека и исходная модель проектов.

Для следующего пользовательского прохода: создать проект без мыши; назначить один sample двум клавишам; изменить только второй; выбрать сцену без её применения; нарезать длинный источник; прервать захват и вернуться; найти Undo без подсказки. Фиксировать фактические затруднения, а не предполагать, что меньшему числу кнопок всегда соответствует лучшее удобство.

## Итоговая проверка реализации

23 автоматические проверки прошли: 18 проверок данных, миграции, сэмплов и WAV; 5 проверок графических моделей, крайних значений и отключения движения при STOP / скрытой вкладке / reduced motion.

Браузером дополнительно проверены: переименование второй дорожки через вложенное меню; удаление именно выбранной дорожки и Undo через Q+E; короткое Z на FINISH; защита CAPTURE при переходе в LIBRARY; постоянный X GRID после выбора соседнего шага; компоновка 640×480 без прокрутки основных редакторов. Ошибок в консоли тестовой сессии не обнаружено.

Механическая проверка оформления: функциональные подписи увеличены до 11 px. Системный Arial во внешней справке оставлен намеренно; здесь важна читаемость рабочего инструмента. Служебный индекс .impeccable/design.json синхронизирован с v0.5: актуальные цвета, компоненты, движение и правила управления. Источники: DESIGN.md, контракт v0.5 и CSS.
