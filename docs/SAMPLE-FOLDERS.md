# Сэмплы, папки и четыре части · MOSS 0.11.1

[English](SAMPLE-FOLDERS.en.md)

Открой **TAPE → SOURCE → X IMPORT** или **VOICE → OPTIONS → ASSIGN / REPLACE SAMPLE → IMPORT FROM DEVICE**. Список показывает папки и WAV в текущем каталоге, а не все файлы сразу.

- **A** — войти в папку или открыть WAV. **B** — подняться на уровень; из корня закрывает выбор. Возвращается прежняя выделенная строка.
- **X** — прослушать выбранный WAV целиком / остановить. Большие исходники проигрываются потоком.
- **R1 + ←/→** — страница. Этот же жест работает в библиотеке подготовленных сэмплов.
- Корни: `imports`, `captures`, общая `MOSS-SampleLibrary` рядом с `Roms`. Каждый каталог показывает до 512 записей; достижение лимита обозначается на экране. Вложенность до 16 уровней.

## Нарезка

После открытия WAV: **L1+R1 → SPLIT INTO FOUR PARTS**. Четыре части по умолчанию идут стык в стык от начала исходника. Если файл помещается в четыре лимита по 1 МиБ PCM16, он делится на четыре равных участка с округлением до фрейма. У длинного файла берутся четыре последовательных участка по 1 МиБ; остаток остаётся вне нарезки. Это не поиск транзиентов. Цвета Y/B/A/X обозначают области поверх реальной волны; активная область плотнее и обведена. Стереоканалы показаны отдельно.

| Действие | Управление |
|---|---|
| Прослушать участок 1 / 2 / 3 / 4 | Коротко **Y / B / A / X** |
| Остановить выбранный участок | Ещё раз та же кнопка |
| Сразу прослушать другой участок | Его кнопка |
| Переместить участок, сохранив длину | Его кнопка + **←/→**, по 1 мс |
| Крупное перемещение | Его кнопка + **↑/↓**, по 100 мс |
| Выбрать участок без звука | Стрелки |
| Переключать MOVE / TRIM / FINE | Короткие **L1 / R1** |
| Точно сдвигать START / END в FINE | **Y / B + ←/→**, один фрейм исходника; **↑/↓**, десять |
| Масштаб / положение окна FINE | **A / X + стрелки** |
| Состыковать части снова | **L1+R1 → ARRANGE PARTS IN ORDER** |
| Изменить границы в TRIM | **Y START / B END / A FADE IN / X FADE OUT** + стрелки |
| Сохранить набор | **L1+R1 → NAME + SAVE FOLDER** |

Удержание стрелки ускоряет изменение. После жеста редактирования отпускание кнопки не запускает звук. В TRIM и FINE короткие нажатия тоже прослушивают четыре соответствующих участка; номер редактируемого участка виден в заголовке. Изменение границ останавливает текущий предпросмотр: следующее нажатие использует новые границы. Участки могут перекрываться и не обязаны идти по времени: номера определяют будущие слоты.

В обычном TAPE вкладки идут SOURCE / MOVE / TRIM / FINE / LIBRARY; в импорте VOICE — MOVE / TRIM / FINE. FINE показывает точные номера фреймов START/END; эти границы сохраняются в WAV без округления до миллисекунд. Один фрейм при 44,1 kHz — около 0,023 мс. Масштаб начинается с выбранной части; ZOOM увеличивает, VIEW перемещает окно. Если редактируемая граница выходит из окна, вид следует за ней.

ARRANGE PARTS IN ORDER сохраняет длины и fade, укладывая части по порядку Y/B/A/X от позиции первой. Если до конца не хватает места, весь набор сдвигается влево. Если суммарная длина больше исходника, команда ничего не меняет и предлагает укоротить части.

Папка получает имя с обычной панели символов. В ней сохраняются `01.wav`–`04.wav` и служебный `set.moss`. Существующая папка не перезаписывается: выбери другое имя. При ошибке остаётся редактор с нарезкой; незавершённый набор не публикуется в библиотеке. **SELECT** выходит из режима; при импорте из VOICE возвращает в инструмент без назначения. Ручной режим START/END сохранён.

## Назначение

В библиотеке **A** открывает папку набора. **Y** на папке или внутри неё загружает все четыре файла на слоты **1–4 текущей дорожки SAMPLER**. Синтезатор или GRANULAR нельзя заменить набором этим действием. Для отдельного назначения в SAMPLER/GRANULAR открой папку и выбери нужный файл через **A**. **X** прослушивает выбранный файл.

Набор заменяет сэмплы и настройки четырёх слотов, сохраняя шаги дорожки и эффекты. Действие можно отменить через OPTIONS → UNDO LAST EDIT. Если один файл не читается, назначения не меняются. При нарезке, начатой из SAMPLER, команда **NAME FOLDER + ASSIGN FOUR** сохраняет и сразу назначает набор.

## Хранение и память

Каталог вмещает 256 подготовленных сэмплов, включая содержимое наборов. Постоянные идентификаторы сохраняются в секвенциях MS17; чтение старых форматов MOS5–MS16 остаётся. Старые WAV, имена и проекты не переписываются при обновлении. Новые секвенции с идентификаторами выше 31 требуют MOSS 0.11.

PCM остаётся в фиксированном кэше **32 × 1 МиБ** плюс прежний рабочий буфер 1 МиБ. Открытие секвенции/назначение подготавливает нужные файлы при остановленном аудио. Callback читает только готовые представления PCM и не открывает файлов. SONG заранее загружает объединение сэмплов всех слотов; больше 32 различных сэмплов отклоняется до старта. Никаких чтений с карты при переходе между секвенциями SONG.

Кнопки на Windows: физическим **Y/B/A/X** соответствуют **Z/X/C/V**, L1/R1 — **Q/E**. Остальные назначения — в [руководстве](../native/prototype/README.md).

## Уровень звука · 0.11.1

Нарезка PCM16 без fade сохраняет значения отсчётов точно; изменения fade намеренно меняют края. Исходник и готовый сэмпл теперь прослушиваются с одинаковым единичным усилением. MASTER-ресэмплинг записывает слышимый выход проекта после усиления и защиты пиков, без предпрослушивания. Старые WAV не переписываются. При воспроизведении через дорожку дополнительно действуют velocity, LEVEL слота/дорожки, эффекты и MASTER.
