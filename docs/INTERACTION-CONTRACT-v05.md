# MOSS · контракт управления v0.5

## Иерархия

ATLAS содержит проекты. Открытие проекта ведёт в GRID; внутри проекта три основные вкладки GRID / MIX / TAPE. GRID содержит только обзор дорожек VOICE + SPACE. Открытие дорожки ведёт в PATTERN / VOICE / SPACE. MIX содержит LEVELS / MASTER FX / SCENES; TAPE — SOURCE / EDIT / LIBRARY. Сцена остаётся полным снимком музыкальных данных, включая состав дорожек и все паттерны.

## Кнопки

| Ввод | Поведение |
|---|---|
| L1/R1 · Q/E | Предыдущий/следующий видимый объект; без зацикливания |
| L2/R2 · [/] | Основные вкладки текущего уровня; циклически |
| L1+R1 · Q+E | OPTIONS текущего экрана; одиночное действие ждёт отпускания |
| D-pad | Локальный выбор; без применения сцены/загрузки проекта |
| Z/X/C/V + стрелки | Слот 1/2/3/4; удержание стрелки ускоряет числа |
| A коротко · Z | Действие / триггер / назначение |
| B коротко · X | Меню закрыть, иначе один уровень назад |
| Y коротко · V | STEP/LOCKS либо раздел MIX/TAPE |
| X коротко · C | В PATTERN переключить шаг/поля |
| SELECT · Tab | Отменить жест/меню, иначе ATLAS |
| START · Space | Транспорт; STOP снимает очередь сцены |

## Объект Q/E

ATLAS: проект; GRID/PATTERN/VOICE/SPACE/LEVELS: дорожка; SCENES: слот; TAPE EDIT: слайс; TAPE LIBRARY: файл. MASTER FX, TAPE SOURCE, отсутствие объекта: пара неактивна, footer показывает —. Навигация не изменяет музыкальные данные. В SAMPLER D-pad выбирает клавиши и переходит между диапазонами; Q/E остаётся сменой дорожки.

Приоритет: текст → меню → активный жест → защита выхода CAPTURE → обычная навигация. Во время жеста курки не меняют объект. Q+E не успевает сначала переключить дорожку. Потеря фокуса очищает зажатые курки и останавливает повтор. Меню восстанавливает фокус инициатора. Один жест — один Undo; Undo доступен из OPTIONS и на клавиатуре.

## Объекты и восстановление

TAPE создаёт черновик из WAV заголовков или симуляции захвата. Новый черновик имеет один диапазон; нарезка — только по явной команде. SAVE добавляет metadata-assets в общую библиотеку. SAMPLER хранит независимые назначения assetId/pitch/start/end/level/playMode на клавишах. Шаг выбирает только доступные назначения. Удаление назначения оставляет номер KEY; отсутствующий файл не заменяется соседним.

Выход из CAPTURE: STAY / FINISH / DISCARD. Черновик, проекты и библиотека сохраняются отдельно от навигационных состояний. Старые данные v1 остаются нетронутыми; v2 хранит миграцию. WAV/PCM ресэмплинг, физическая запись слайсов и ARM-производительность ещё не реализованы.

## Состояния

Пустой проект даёт ADD TRACK; пустая клавиша — ASSIGN; пустая LIBRARY — путь к SOURCE. ONE SHOT явно выключает GATE. Превышение предварительных лимитов 1 MiB/asset и 8 MiB/активный набор сообщает причину. Ошибки сохранения и импорта не выдаются за успех. Полные исходники и метаданные проекта остаются доступны для экспорта и восстановления.
