# MONO 0.9 · звук и управление

**Русский** · [English](MONO-v09.en.md)

MONO переработан как компактный монофонический subtractive-синтезатор для RG35XX. Ориентир — плотный бас, мягкие движущиеся тембры и резонансные кислотные линии. Это самостоятельный DSP MOSS, а не эмуляция схемы Mother-32 и не перенос закрытой прошивки. ORGANISM и FM сохраняют свои движки.

## Что изменилось

Два bandlimited-осциллятора SAW/PULSE, синусоидальный SUB на октаву ниже и шум идут в четырёхкаскадный резонансный low-pass. При DETUNE=0 работает один основной осциллятор; с расстройкой плавно подключается второй. Нелинейная обратная связь фильтра решается с двумя ограниченными итерациями, обработка выполняется на удвоенной частоте и возвращается к 32 kHz через half-band FIR. Таблицы насыщения и коэффициентов готовятся заранее; в обработке звука нет выделения памяти.

В прежнем MONO резонанс уменьшал основной тон, а компенсация возвращала лишь часть уровня. В новом фильтре усилена компенсация тела звука; DC-фильтр настроен на 3 Hz. В одинаковом сухом тесте E1/A1/E2 при RESONANCE=85 основной тон выше прежнего на **6.11–6.14 dB**. При нулевом резонансе прибавка **1.46–1.57 dB**. Это сравнение цифрового выхода голоса при конкретных настройках, не измерение выхода для наушников и не оценка качества на слух.

Амплитуда получила ADSR, фильтр — отдельный DECAY и биполярную глубину огибающей. GLIDE при перекрывающихся нотах сохраняет огибающие и плавно меняет высоту. Фазы и состояние фильтра не обнуляются на каждом активном триггере. Локи без ноты меняют звучащий голос без перезапуска.

## Пять страниц

В VOICE короткие **L1 / R1** переключают страницы. На Windows — **Q / E**. Порядок полей прежний: **Y / B / A / X**; удержание кнопки и ←/→ меняет значение точно, ↑/↓ — крупнее. В PATTERN → VOICE LOCKS страницы переключаются **L1 + стрелки**, а L1/R1 выбирают STEP / VOICE LOCKS / FX LOCKS / TIMING.

| Страница | Y | B | A | X |
|---|---|---|---|---|
| CORE | CUTOFF 20–12000 Hz | RESONANCE 0–100% | ATTACK 0–5000 ms | RELEASE 0–10000 ms |
| COLOR | ENV AMT −100…100% | SUB 0–100% | NOISE 0–100% | DRIVE 0–100% |
| OSC | PULSE W 5–95% | DETUNE 0–30 cents | GLIDE 0–2000 ms | DRIFT 0–100% |
| ENV | DECAY 10–8000 ms | SUSTAIN 0–100% | FLT DECAY 10–8000 ms | KEY TRACK 0–100% |
| MOTION | LFO RATE 0.01–20 Hz | PWM 0–100% | VCF MOD 0–100% | VIBRATO 0–100 cents |

SAW/PULSE выбирается в контекстных опциях L1+R1. PULSE W и PWM слышны в PULSE. LFO RATE имеет точный шаг 0.01 Hz и крупный 0.1 Hz. DETUNE — расстройка второго осциллятора, VIBRATO — глубина периодического изменения высоты; DRIFT добавляет более медленное случайное движение. Один LFO управляет PWM, VCF MOD и VIBRATO. ATTACK общий для старта обеих огибающих; FLT DECAY отделён от амплитудного DECAY. KEY TRACK=100% даёт октаву cutoff на октаву нот относительно C3/MIDI48.

Минимальная атака внутри движка — 3 ms, release — 5 ms: нулевые значения не создают жёсткую ступень. DECAY и GLIDE обозначают приблизительное время подхода к цели, а не линейное достижение абсолютного нуля. SUB, DRIVE и RESONANCE взаимодействуют, поэтому одинаковое положение регуляторов не означает одинаковую громкость всех тембров.

Все двадцать параметров доступны в локах, включая LOCK ONLY и RESET. Для мягкого движения начни с **SOFT**, PULSE, затем PWM/VCF MOD; для баса — **SUB**; для короткой резонансной линии — **ACID**. Названия четырёх пресетов сохранены, их MONO-настройки обновлены.

## Экран

Волна показывает реальные отсчёты голоса **до эффектов и уровня дорожки**, без автоматического увеличения амплитуды. На 32 kHz окно составляет 32 ms. Справа — текущая частота фильтра с учётом модуляции и две огибающие; GATE / RELEASE / IDLE объясняют состояние. При остановке — нулевая линия. Это компактная осциллограмма с разреженными отсчётами, не спектроанализатор: высокие частоты по ней нельзя измерять.

Проверены открытые исходники FM-1 и amsynth; закрытые бинарники Moog/u-he/TAL не декомпилировались. GPL-код этих проектов в MOSS не скопирован. Реализация собственная; выводы о характере источников основаны на устройстве кода и документации, а не на сравнительном прослушивании всех инструментов.

## Файлы и проверки

Новые сохранения — **MS15**, чтение **MOS5…MS14** сохраняется. Для старых MONO-патчей новые модуляции выключены, ширина импульса 50%, sustain 100%; FLT DECAY получает прежнюю связь с RELEASE. Звук всё равно меняется из-за нового фильтра. Старый бинарник не читает MS15: откат требует также исходной копии проектов.

Проверки включают обе формы волны, крайние значения, быстрые локи, 8/32/44.1/96 kHz, glide/legato, release, все двадцать локов и реальный MS14. [Доказательства и короткие замеры на RG35XX](verification/mono-v09/README.md).

Для повторения сухих фраз: `node native/prototype/scripts/mono-render.cjs`, затем `python native/prototype/scripts/mono-analyze.py`. Четыре 12-секундных WAV появятся в `work/mono-research/audio/`. Они предназначены для прослушивания; численные проверки не заменяют твою оценку тембра.
