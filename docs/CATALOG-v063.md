# Каталог исходных WAV · 0.6.3-dev

**Русский** · [English](CATALOG-v063.en.md)

Лимит 128 файлов скрывал часть больших паков. Теперь каталог вмещает **2048 исходных WAV**, а R1+←/→ перемещает выбор на семь строк — ровно одну видимую страницу. Это общий список с рекурсивным поиском в подпапках, без отдельной навигации по папкам. Глубина поиска остаётся прежней: корень и пять уровней ниже.

Таблица путей занимает дополнительно **960 KiB**. Звуковые данные не загружаются при сканировании: банк остаётся на 32 подготовленных образца до 1 MiB PCM16 каждый. Декодер, потоковый проигрыватель, DSP и формат MOS9 не изменены. Стабильная установка MOSS 0.5.2 не обновлялась.

## Проверка 13 ноября 2026

- На Windows и оригинальной RG35XX / GarlicOS 1.4.9 открыты заголовки всех **469 WAV SHAPES**. Проверены переход через индекс 128, неполная последняя страница, предел 2048 и добавление источника в заполненный каталог.
- В изолированной тестовой папке проверены потоковое предпрослушивание длинного WAV и сохранение именованного слайса до 1 MiB. Пользовательская библиотека не использовалась для тестового сохранения.
- В обычном приложении отображаются **570 файлов**: 567 из общей библиотеки и три записи. Проверены выбор файла 141, его предпрослушивание и открытие EDIT с ограничением 1024 KiB.
- MENU завершил приложение с кодом 0; восстановлен governor `interactive`. Все девять файлов секвенций/SONG и служебных данных совпадают с резервной копией по SHA256.

Расширенная проба старой библиотеки остановилась на `Master Sample Pack/Hollywoodedge,_Screams_2_Woman_Singl_PE133601.wav`: текущий декодер отверг его формат (`USE PCM16/24/32 OR FLOAT32 WAV`). Поэтому успешная проверка форматов относится ко всем 469 новым WAV, а не ко всем 567 старым и новым файлам. Поддержка форматов в этой правке не менялась.

Длительные аудионагрузочные тесты по просьбе пользователя **не повторялись**. В обычном сеансе не было превышений времени аудиообработки и опустошений потока; зарегистрированы три длинных интервала между callback и три медленных UI-кадра, максимум 60.517 ms. Это проверка каталога и взаимодействия, а не новая квалификация максимальной DSP-нагрузки. Отчёт 0.6.2 относится к своему точному бинарнику.

Данные и SHA256 новой сборки: [manifest.json](verification/catalog-v063/manifest.json). Журналы целевых тестов и обычного запуска лежат рядом. Пользовательские аудиофайлы не включены в репозиторий.

Исходник целевого теста: `native/prototype/tests/catalog_test.cpp`. Аргументы: корень WAV-пака и ожидаемое число файлов. Запускать из отдельной пустой рабочей папки: тест сохраняет один подготовленный слайс в её `library/`.
