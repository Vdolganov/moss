# MOSS

**Русский** · [English](README.en.md) · [Документация](docs/README.md)

Standalone groovebox для оригинальной **Anbernic RG35XX**: музыка кнопками консоли, без дополнительных плат. Общий C++17 движок также работает на Windows.

**Текущая версия в `main` — MOSS 0.13.1:** обновлённые ORGANISM и FM, импорт папок и нарезка комплектов, монохромный интерфейс и исправленный уровень SAMPLER/GRANULAR. [Изменения громкости и проверка](docs/LEVELS-v0131.md). Последние готовые архивы — [0.9.0](https://github.com/Vdolganov/moss/releases/tag/v0.9.0); они не включают эти изменения.

## Возможности

- До четырёх дорожек: **MONO, ORGANISM, FM, SAMPLER, GRANULAR**.
- MONO: 20 параметров, пять страниц, насыщаемый резонансный фильтр, SUB, noise, detune, glide, drift, PWM, LFO и реальные осциллограмма/огибающие.
- GRANULAR / LENS: до восьми зёрен на дорожку, длина до 8 секунд, scatter, reverse, случайные скачки, огибающие, detune и freeze.
- SAMPLER: четыре собственных назначения и рисунка ударов на экземпляр; one-shot, pitch, ручные start/end, длительность и локи.
- Независимые циклы до 512 тиков 1/64; разрешения 1/8–1/64, probability, SWING/SHIFT, локи с нотой и **LOCK ONLY**, аудиоповтор REPEAT.
- **ORBIT, POND, DRIVE, CRUSH, REEL**; до двух активных эффектов на дорожке и двух на мастере. REEL включает насыщение, окраску, wow/flutter и дефекты ленты.
- TAPE: импорт WAV из папок, потоковое прослушивание, ручная нарезка или комплект из четырёх частей, точная подстройка и внутренний ресэмплинг.
- До 32 секвенций и 32 SONG по 64 слота: общий BPM, повторы, длина в тактах, независимые вариации.
- Экран 640×480, четыре параметра под физические Y/B/A/X, Undo и экранная клавиатура.

Подготовленная библиотека: до 256 образцов, в памяти до 32, каждый до 1 MiB PCM16. Каталог исходных WAV — до 2048 файлов. Аудио: 32 kHz / 1024 стереофрейма, штатные 1.008 GHz без разгона. Новые секвенции — **MS18**, чтение MOS5…MS17; SONG — SON1.

## Скачать и установить

[Релиз 0.9.0: архивы и контрольные суммы](https://github.com/Vdolganov/moss/releases/tag/v0.9.0). Это приложение, не образ GarlicOS. Проверяемая платформа — оригинальная RG35XX / GarlicOS 1.4.9. Другие RG35XX и GarlicOS 1.3.9 этой версией не подтверждены. Условия и границы проверок указаны в релизе.

**GarlicOS:** скопируй `Roms` из архива на карту; запуск — **Consoles → APPS → MOSS**. Итоговые пути: `Roms/APPS/MOSS.sh` и `Roms/APPS/MOSS/`.

**Windows:** распакуй весь архив в доступную для записи папку и запусти `MOSS.exe`. `samples/` должна остаться рядом. Движок общий с консолью; скорость компьютера не является проверкой производительности RG35XX.

Перед обновлением сохрани полную копию установленной папки. Сохраняй свои `projects/`, `samples/`, `library/`, `imports/`, `captures/`; тестовые WAV не должны заменять личные файлы.

**Переход с MOSS-GRANULAR:** сохрани обе старые папки. Используй целиком актуальные данные MOSS-GRANULAR как основу новой папки MOSS, затем замени бинарник и launcher. Не смешивай `projects/` и `library/` разных установок по отдельным файлам: номера секвенций и образцов могут совпадать. После проверки перенеси старую папку MOSS и отдельный launcher MOSS-GRANULAR в резервную копию вне APPS. Подробности — [руководство](native/prototype/README.md).

MS18 не читается старыми версиями. Для отката нужны старый бинарник **и исходные данные**. Обновлённые инструменты, эффекты и уровни могут изменить звучание старых патчей.

## Управление

| RG35XX | Windows | Действие |
|---|---|---|
| D-pad | Стрелки | Навигация |
| Y/B/A/X + стрелки | Z/X/C/V + стрелки | Четыре поля: ←/→ точно, ↑/↓ крупно |
| A / B | C / X | Подтвердить / назад |
| L1/R1 | Q/E | Банки параметров |
| L2/R2 | [ / ] | Основные вкладки |
| L1 + ←/→; L1 + ↑/↓ | Q + стрелки | Слот/участок; вложенная страница параметров |
| R1 + ←/→ | E + ←/→ | Страница сетки или списка |
| L1+R1 | Q+E | Контекстное меню |
| START | Space | Воспроизведение / стоп |
| SELECT + стрелки | Tab + стрелки | Темп |
| MENU, 2 секунды | Esc, 2 секунды | Сохранить и выйти |

## Сборка

Windows x64, Node.js 18+, Python 3.9+. Локальные Zig 0.14.1 и uClibc SDK устанавливаются с проверкой SHA256; Docker/WSL не нужны.

```powershell
node "hardware lab/scripts/setup.cjs"
node native/prototype/scripts/build.cjs
```

При необходимости задай `MOSS_PYTHON` полным путём к Python. Сборка создаёт ARM/Windows, выполняет проверки движка, сохранений, управления и эффектов. `scripts/package.py` проверяет ABI, тесты и соответствие отчёта устройства точному ARM-бинарнику перед упаковкой GarlicOS.

## Навигация по проекту

- [Нативное руководство RU/EN](native/prototype/README.md), [MONO](docs/MONO-v09.md), [GRANULAR](docs/GRANULAR-INSTRUMENT.md), [REEL](docs/REEL-v1.md).
- `native/prototype/` — текущее приложение, тесты и сборка; `hardware lab/` — диагностика и SDK setup.
- [Текущий браузерный прототип](<visual prototype/current/README.md>) — `visual prototype/current/START.cmd`, без звука. Родительская папка хранит ранний прототип.
- `docs/` и `design/current/` — актуальное руководство, решения и датированные отчёты; старые результаты не приписываются новым бинарникам.
- `releases/` — сведения о релизах. В Git нет личных проектов, записей и сторонних сэмпл-паков. Три исходных тестовых WAV создаются `hardware lab/scripts/make_samples.py`.
