# GRANULAR / LENS · 0.6.1-dev

**Русский** · [English](GRANULAR-INSTRUMENT.en.md)

Один подготовленный сэмпл, до восьми одновременных зёрен на дорожку. Четыре дорожки, по два эффекта на дорожке и мастере. Это отдельный эксперимент **MOSS-GRANULAR**; стабильный MOSS 0.5.2 остаётся отдельно.

## Первое облако

Открой APPS → MOSS-GRANULAR → LENS CLOUD → LENS → VOICE. START запускает секвенцию. Для своего источника: L1+R1 → ASSIGN / REPLACE SAMPLE → готовый сэмпл или + IMPORT FROM DEVICE. Импорт использует ручной выбор START–END в TAPE, имя и сохранение; отмена сохраняет прежнее назначение.

У грануляра одно назначение; четыре ячейки обычного SAMPLER к нему не относятся. Подготовленный PCM16 WAV занимает до **1 MiB**. Границы в VOICE не уменьшают расход памяти: для этого нужно сохранить более короткий файл через TAPE.

## Управление

L1/R1 переключают четыре банка. Порядок полей — **Y / B / A / X** (Windows: Z / X / C / V). Удерживай соответствующую кнопку: ←/→ меняют точно, ↑/↓ крупно. Короткое A прослушивает ноту в течение двух секунд, затем действует NOTE OUT; без источника открывает назначение. Короткое X (Windows V) удерживает якорь сканирования.

| Банк | Y | B | A | X |
|---|---|---|---|---|
| PLAY | SPEED −3…3× | PITCH ±24 полутона | SIZE 1–500 ms | DENSITY 0–128/s |
| SCAN | POSITION 0–100% | START 0–99.9% | END 0.1–100% | SCATTER 0–100% |
| TEXTURE | STEREO 0–100% | IRREGULAR 0–100% | CUTOFF 20–14000 Hz | LEVEL 0–200% |
| ENVELOPE | GRAIN IN 0–100% | GRAIN OUT 0–100% | NOTE IN 0–9000 ms | NOTE OUT 0–9000 ms |

**SCATTER = 100%** распределяет рождения по всему выбранному диапазону. Восемь областей выбираются в случайном порядке с приоритетом свободных: полное облако не собирается возле одной головки. Позиции внутри областей случайны. При меньшей плотности одновременно может звучать меньше восьми зёрен. Это распределение точек рождения, а не обещание неподвижных равномерных точек чтения: каждое зерно продолжает читать со своей высотой.

**SCATTER = 0%** рождает зёрна точно у якоря. Промежуточные значения задают ширину окна вокруг него в долях START–END; окно оборачивается внутри этого диапазона. SPEED перемещает якорь, POSITION устанавливает его, FREEZE удерживает. При 100% эти три управления не влияют на распределение облака; Линза показывает FULL CLOUD / ALL REGIONS, а поля скорости и позиции помечены SCAN ANCHOR.

START/END теперь ограничивают и рождения, и чтение каждого нового зерна. Зёрна, начавшиеся до изменения границ, спокойно заканчивают прежние окна. PITCH задаёт скорость чтения, независимо от SPEED. STEREO закрепляет отдельную панораму за каждым зерном; облако целиком больше не качается из стороны в сторону. IRREGULAR меняет интервалы рождения. Если заняты все восемь голосов, новая попытка пропускается, без обрыва старого зерна.

**GRAIN IN / OUT** — отдельные атака и затухание в процентах SIZE, с плавной косинусной формой. Остаток длительности — плато. Например, SIZE 400 ms, IN 10%, OUT 60%: 40 ms атаки, 120 ms плато, 240 ms затухания. Увеличение одного фейда при нехватке места уменьшает другой. Независимые конфликтующие локи пропорционально приводятся к 100%. Даже нулевой фейд оставляет один нулевой отсчёт на краю окна. Параметры окна фиксируются при рождении; текущие зёрна не обрываются.

**NOTE IN / OUT** управляют появлением и отпусканием всего облака. Это отдельная огибающая: LENGTH шага держит ноту, после него действует NOTE OUT. CUTOFF и LEVEL меняются плавно. Усиление учитывает ожидаемое перекрытие и форму окна, вместо постоянного ослабления в восемь раз; оно не анализирует громкость исходника и не является компрессором. LEVEL позволяет согласовать источники. Общий выход приложения поднят с 135% до 180% (+33% к предыдущей версии), с прежним мягким ограничением пиков. Усиление мониторинга не записывается повторно при внутреннем ресэмплинге.

## PATTERN и Линза

C3 при PITCH 0 читает на исходной высоте. VOICE LOCKS содержит все 16 параметров. L1+стрелки выбирают вложенный банк; L1/R1 остаются навигацией STEP / VOICE LOCKS / FX LOCKS / CYCLE. `--` наследует базовое значение. Лок POSITION перемещает якорь при триггере.

Внешнее кольцо — обзор реального источника. Внутренние кольца показывают возраст активных зёрен, приглушённые метки — рождение, яркие короткие штрихи — текущее чтение. Снимки поступают из аудиодвижка, отдельного таймера анимации нет. Границы и режим учитывают звучащие локи. Без источника — NO SAMPLE / A ASSIGN SAMPLE.

Локи без новой ноты пока **не реализованы**. Предложенное взаимодействие отдельно описано в [TRIGLESS-LOCKS-PLAN.md](TRIGLESS-LOCKS-PLAN.md).

## Формат и проверка

Сохранение — **MOS8**, включая 16 параметров и локов. Чтение MOS5/MOS6/MOS7 сохраняется. В MOS7 бывший ненулевой JITTER преобразуется в SCATTER 100%, нулевой — в 0%; старые локи JITTER очищаются, поскольку миллисекунды не эквивалентны доле диапазона. Старый FADE и его локи переносятся в NOTE IN и NOTE OUT; LEVEL получает 100%. Остальные ноты, источники и параметры сохраняются. Загрузка не перезаписывает файл сама по себе. Стабильный MOSS 0.5.2 не читает MOS8; работай с отдельной экспериментальной копией.

Актуальная проверка новой версии: [GRANULAR-CLOUD-v2.md](GRANULAR-CLOUD-v2.md). Старый [GRANULAR-NATIVE-v1.md](GRANULAR-NATIVE-v1.md) относится только к 0.6.0-dev. Линейная интерполяция по-прежнему может давать алиасинг при большой транспозиции вверх. Это собственный DSP, не порт кода Mangl.

[Браузерный этюд](../visual%20prototype/granular.html) остаётся без звука и с синтетическими источниками. Он отражает четыре банка и распределение облака, но не заменяет проверку аудио. В этюде короткое C / A включает FREEZE; нативное управление X / V отличается намеренно.
